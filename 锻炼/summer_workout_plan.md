# 暑假增肌锻炼计划

适用情况：男，身高 165cm，体重约 105 斤，偏瘦，目标是增肌、改善体态和体能。计划按 8 周设计；如果暑假更长或更短，可以按周循环或截取执行。每日运动时间控制在 1.5 小时以内。

> 如果有心血管疾病、关节伤、腰椎问题或长期疼痛，先降低强度或咨询医生/康复师。训练中出现刺痛、眩晕、胸闷，应立即停止。

## 总体原则

1. 增肌优先级：力量训练 > 吃够 > 睡够 > 少量有氧。
2. 不追求极限自律，目标是“暑假大多数天能完成”。每周完成 4 次力量训练就合格。
3. 每次训练控制在 60-80 分钟：热身 8-10 分钟，正式训练 45-60 分钟，拉伸 5-10 分钟。
4. 每组动作保留 1-3 次余力，不需要练到完全力竭。
5. 每周记录 1 次体重、围度和训练重量。体重每周增加 0.2-0.4kg 比较理想。

## 每周安排

推荐训练时间：傍晚 17:00-18:15 或晚饭前 1.5-2 小时。若作息不同，固定在每天相近时间即可。

| 星期 | 时间 | 内容 | 时长 |
| --- | --- | --- | --- |
| 周一 | 17:00-18:15 | 上肢推：胸、肩、三头 | 65-75 分钟 |
| 周二 | 17:00-18:15 | 下肢：腿、臀、核心 | 65-75 分钟 |
| 周三 | 17:30-18:10 | 轻活动：快走、拉伸、体态 | 30-40 分钟 |
| 周四 | 17:00-18:15 | 上肢拉：背、二头 | 65-75 分钟 |
| 周五 | 17:00-18:15 | 全身增肌训练 | 65-80 分钟 |
| 周六 | 任意时间 | 可选：球类、游泳、骑车、快走 | 30-60 分钟 |
| 周日 | - | 休息 | - |

最低执行版本：如果某周很忙，只完成周一、周二、周四、周五。  
更轻松版本：周六完全休息，只保留散步。

## 每次训练通用流程

### 热身 8-10 分钟

1. 原地慢跑或跳绳 3 分钟。
2. 肩绕环、髋绕环、踝关节活动各 30 秒。
3. 徒手深蹲 15 次。
4. 俯卧撑支撑位肩胛前伸后缩 10 次。
5. 当天第一个正式动作先用轻重量做 1-2 组。

### 强度标准

| 感受 | 含义 |
| --- | --- |
| 太轻 | 做完还能轻松多做 5 次以上，下次加重量或加次数 |
| 合适 | 做完还能多做 1-3 次，保持 |
| 太重 | 动作变形、憋气明显、关节不舒服，立刻减重 |

### 周三：轻活动和体态

总时长 30-40 分钟，不追求累。

1. 快走 20-25 分钟，能说话但略喘。
2. 胸椎伸展 2 x 10 次。
3. 髋屈肌拉伸 2 x 40 秒/侧。
4. 腘绳肌拉伸 2 x 40 秒/侧。
5. 墙天使 3 x 10 次。

## 8 周进阶方式

| 阶段 | 周数 | 目标 | 做法 |
| --- | --- | --- | --- |
| 适应期 | 第 1-2 周 | 学动作、不过度疲劳 | 每个动作先用保守重量，动作标准优先 |
| 增量期 | 第 3-6 周 | 稳定增加训练量 | 每个动作达到次数上限后，下次小幅加重量 |
| 巩固期 | 第 7 周 | 保持强度，避免疲劳堆积 | 每个动作少做 1 组或重量降 10% |
| 测试期 | 第 8 周 | 看进步 | 记录卧推/深蹲/硬拉或替代动作的最佳 8-12 次重量 |

进步规则：

1. 某动作目标是 8-12 次时，如果所有组都能做 12 次，下次加重量。
2. 健身房动作每次加 2.5-5kg；哑铃每只加 1-2kg；居家训练可以先加次数，再加背包重量。
3. 如果连续两次状态差，不加重量，先保证动作和睡眠。

## 饮食计划

### 热量目标

你目前偏瘦，增肌需要轻微热量盈余。先按以下方式执行 2 周：

- 每天比平时多吃 300-500 千卡。
- 蛋白质每天 85-110g。
- 每天喝水 1.8-2.5L。
- 如果 2 周体重完全没涨，每天再加一份主食或一杯牛奶。

### 简单估算

| 营养 | 每日建议 |
| --- | --- |
| 蛋白质 | 85-110g |
| 碳水 | 每餐都要有，训练日前后多一点 |
| 脂肪 | 不要太低，保留鸡蛋、坚果、鱼肉、牛奶 |
| 蔬果 | 每天 1-2 份水果、至少 2 碗蔬菜 |

### 每日饮食模板

| 时间 | 吃什么 |
| --- | --- |
| 早餐 | 牛奶/豆浆 + 鸡蛋 2 个 + 面包/燕麦/馒头 + 水果 |
| 午餐 | 米饭/面/土豆 + 鸡胸/牛肉/鱼/猪瘦肉/豆腐 + 蔬菜 |
| 训练前 1-2 小时 | 香蕉/面包/酸奶/饭团，选一种 |
| 训练后 1 小时内 | 正餐优先；如果不方便，牛奶 + 面包/香蕉 |
| 晚餐 | 主食 + 肉/蛋/豆制品 + 蔬菜 |
| 睡前可选 | 牛奶/酸奶/豆浆，胃口好可以加一小把坚果 |

### 一天示例

- 早餐：燕麦 60g + 牛奶 300ml + 鸡蛋 2 个 + 香蕉 1 根。
- 午餐：米饭 1.5-2 碗 + 鸡腿/牛肉/鱼 150-200g + 青菜 1-2 碗。
- 训练前：面包 1 个或酸奶 1 杯。
- 晚餐：米饭/面条 + 豆腐或瘦肉 150g + 蔬菜。
- 睡前：牛奶 250ml。

## 增肌加餐选择

不想算热量时，每天从下面选 1-2 个：

| 加餐 | 适合时间 |
| --- | --- |
| 牛奶 250-500ml | 早餐、睡前 |
| 酸奶 + 香蕉 | 训练前后 |
| 花生酱面包 | 下午 |
| 鸡蛋 1-2 个 | 早餐或晚餐 |
| 坚果一小把 | 下午，但不要吃太多 |
| 牛肉干/鸡胸肉/豆干 | 不方便吃正餐时 |

## 作息和恢复

1. 每天尽量睡 7.5-9 小时。增肌很依赖睡眠。
2. 晚上训练后不要立刻熬夜打游戏到很晚，至少保证第二天不明显疲劳。
3. 肌肉酸痛可以训练，但关节疼痛不要硬撑。
4. 每天久坐超过 1 小时，起身活动 3-5 分钟。

## 调整规则

| 情况 | 怎么调 |
| --- | --- |
| 2 周体重没涨 | 每天加一份主食或 250-500ml 牛奶 |
| 胃口太撑 | 少食多餐，把加餐拆到上午和下午 |
| 体重涨太快、肚子明显变大 | 每天减少一份高热量零食或半碗主食 |
| 训练很累、影响生活 | 每个动作少做 1 组，持续 1 周 |
| 某动作关节不舒服 | 换替代动作，不硬练 |

## 每周最低合格线

如果某段时间状态一般，只要做到下面 4 件事，这周就算没有崩：

1. 完成 4 次力量训练中的 3 次。
2. 每天至少吃到 2 个鸡蛋或等量蛋白质。
3. 每天多吃一份主食或喝一杯牛奶。
4. 每晚尽量睡够 7 小时。

## 暑假结束时的目标

比较合理的结果：

- 体重增加 1.5-3kg。
- 俯卧撑、深蹲、划船等基础动作明显更稳。
- 肩背更挺，手臂和胸背围度有变化。
- 形成一套不用特别痛苦也能坚持的训练节奏。
