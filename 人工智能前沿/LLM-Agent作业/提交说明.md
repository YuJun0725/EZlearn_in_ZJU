# 杭州旅行规划 Agent 提交说明

## 内容

本提交包含主结构化 Agent、轻量 RAG 对比基线、杭州 POI 数据集、测试代码、评测结果、Web 展示层和项目总报告。

项目没有包含真实 API Key。首次运行前请复制 `.env.example` 为 `.env`，再按需填写高德 Web 服务 Key 和大模型配置。

## 快速运行

```powershell
python app.py
```

运行测试：

```powershell
python -m unittest discover -s tests -v
```

启动 Web 展示层：

```powershell
python web_app.py
```

浏览器访问 `http://127.0.0.1:8765/`。

自然语言输入和 RAG + LLM 对比需要在 `.env` 中配置兼容 OpenAI 接口；离线结构化示例、POI 查询、测试和评测不需要联网。

## 主要文档

- `项目总报告.md`：实验设计、实现过程、运行方法、测试结果和分析。
- `README.md`：项目配置、数据构建和运行说明。
- `eval/测试报告.md`：自动化测试、离线评测、性能和联网测试结果。
- `rag_baseline/README.md`：轻量 RAG 基线及自然语言渲染方法。
