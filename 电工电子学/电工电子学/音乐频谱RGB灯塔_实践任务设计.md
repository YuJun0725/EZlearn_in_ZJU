# 桌面音乐频谱 RGB 灯塔实践任务设计

## 1. 项目概述

本实践任务的目标是设计一块低压安全的桌面电子作品：**音乐频谱 RGB 灯塔**。

它使用 USB-C 提供 5V 电源，通过麦克风采集环境声音，再经过模拟电路放大、滤波或包络检测，最后由单片机控制 RGB 灯珠显示音乐节奏。最终成品可以放在桌面上，播放音乐时灯光会随鼓点、音量和频率变化。

这个项目适合作为学习《电工电子学》后的综合实践，因为它同时涉及：

- 电阻、电容、二极管、三极管或 MOSFET 等基础器件
- 运算放大器的单电源应用
- 交流耦合、偏置、滤波和整流
- 模拟信号采集与 ADC 转换
- 数字 LED 控制
- USB 5V 电源处理
- PCB 原理图设计、封装选择、布局布线和调试

## 2. 项目安全边界

本项目只使用 **5V 直流低压供电**，不直接连接 220V 市电。

安全要求：

- 使用手机充电器、电脑 USB 口或 5V 移动电源供电。
- 不设计、不焊接、不测试任何 220V 交流输入电路。
- 如果后期想做市电供电版本，应使用成品隔离电源模块，并单独学习安规、爬电距离、保险丝、压敏电阻和隔离测试等内容。

本实践阶段建议严格限制在 5V USB 供电范围内。

## 3. 最终效果

完成后，作品应具备以下表现：

- 安静环境下，RGB 灯呈现缓慢呼吸效果。
- 音乐响起时，灯光亮度随音量变化。
- 鼓点明显时，灯光快速扩散或闪烁。
- 如果做三频段版本，低频、中频、高频分别控制不同颜色。
- PCB 可以做成圆形、三角形或长条形，具有一定外观设计感。

推荐基础外观：

- 圆形 PCB，直径约 `60 mm ~ 80 mm`
- 外圈放置 16 颗 RGB 灯珠
- 中间放置麦克风和主控
- 板边放 USB-C 接口
- 背面放调试焊盘和版本信息

## 4. 功能需求

### 4.1 基础版功能

基础版重点是降低第一次做板风险，保证可以成功调通。

必须实现：

- USB-C 5V 输入
- 电源滤波和电源指示灯
- 驻极体麦克风采集声音
- 运放放大声音信号
- 包络检测输出音量电压
- 单片机 ADC 读取音量
- 16 颗 WS2812B 或 SK6812 RGB 灯珠显示音量变化
- 预留下载接口或使用开发板模块

基础版灯效：

- 音量越大，点亮的灯珠越多。
- 音量越大，灯珠亮度越高。
- 无声音时，灯光进入低亮度呼吸状态。

### 4.2 进阶版功能

进阶版可以在基础版稳定后再做。

可选实现：

- 三路频段检测：低频、中频、高频
- 自动增益或软件音量归一化
- 按键切换灯效模式
- 电位器调节灵敏度
- OLED 显示当前模式或音量
- 蓝牙或 Wi-Fi 控制灯效
- 外接灯带接口

## 6. 电路模块设计

## 6.1 USB-C 5V 电源输入

如果只需要从普通 USB-C 充电器取 5V，USB-C 接口的 CC 引脚需要下拉电阻，让充电器识别这是一个用电设备。

典型连接：

```text
CC1 ---- 5.1kΩ ---- GND
CC2 ---- 5.1kΩ ---- GND
VBUS ---------------- +5V
GND ----------------- GND
```

建议器件：

| 名称 | 推荐值/型号 | 作用 |
| --- | --- | --- |
| USB-C 母座 | 16Pin 沉板或贴片接口 | 5V 输入 |
| Rcc1 | 5.1kΩ | CC1 下拉 |
| Rcc2 | 5.1kΩ | CC2 下拉 |
| C1 | 470uF | RGB 灯瞬态电流缓冲 |
| C2 | 10uF | 电源滤波 |
| C3 | 100nF | 高频去耦 |
| D1 | LED | 电源指示 |
| Rled | 1kΩ | 电源指示灯限流 |

电源指示灯电阻计算：

```text
R = (5V - 2V) / 3mA
R = 1000Ω
```

所以选择 `1kΩ` 比较合适。

## 6.2 RGB LED 灯珠电路

推荐使用 `WS2812B-2020`、`WS2812B-5050` 或 `SK6812`。

优点：

- 每颗灯珠内部集成 RGB LED 和驱动芯片。
- 只需要一根数据线级联。
- 可以实现丰富灯效。

典型连接：

```text
单片机 GPIO ---- 330Ω ---- DIN 第 1 颗 RGB 灯

第 1 颗 DOUT ------------ DIN 第 2 颗
第 2 颗 DOUT ------------ DIN 第 3 颗
...
```

每颗灯珠的电源脚附近建议放置一个 `100nF` 去耦电容。

RGB 灯电流估算：

单颗 RGB 灯全白最大电流约 `60mA`。

如果使用 16 颗：

```text
Imax = 16 × 60mA = 960mA
```

实际灯效中不建议长时间全白满亮。软件中可以限制总亮度，例如设置最大亮度为 30%：

```text
Ityp ≈ 960mA × 30% = 288mA
```

因此，5V 电源建议至少支持 `1A`，更推荐 `5V 2A`。

PCB 设计要求：

- LED 电源主干线尽量粗，建议 `0.8 mm ~ 1.2 mm`。
- GND 使用铺铜。
- USB-C 输入附近放 `470uF` 或更大的电解电容。
- 数据线串联 `330Ω` 电阻，靠近第一颗灯珠或靠近主控均可。

## 6.3 麦克风采集电路

基础版推荐使用驻极体麦克风。驻极体麦克风内部通常包含一个小型场效应管，需要外部偏置电阻。

典型偏置电路：

```text
+5V
 |
2.2kΩ
 |
Mic_Out
 |
驻极体麦克风
 |
GND
```

`Mic_Out` 上会叠加一个直流偏置和很小的交流声音信号。声音信号幅度通常只有几毫伏到几十毫伏，不能直接稳定驱动后级，需要经过交流耦合和运放放大。

建议器件：

| 名称 | 推荐值/型号 | 作用 |
| --- | --- | --- |
| MIC1 | 驻极体麦克风 | 声音采集 |
| Rmic | 2.2kΩ | 麦克风偏置 |
| Ccouple | 1uF | 隔直流、传递交流信号 |

## 6.4 运放偏置电路

因为本项目使用单电源 5V，运放无法处理低于 GND 的负电压信号。声音是交流信号，所以需要把信号中心抬到一个中间电压，例如 `2.5V`。

使用两个电阻分压产生中点电压：

```text
+5V
 |
100kΩ
 |
Vbias = 2.5V
 |
100kΩ
 |
GND
```

并在 `Vbias` 对地加电容滤波：

```text
Vbias ---- 10uF ---- GND
Vbias ---- 100nF --- GND
```

这样 `Vbias` 会成为声音放大电路的参考中心点。

## 6.5 运放放大电路

推荐使用低压、轨到轨输入输出或接近轨到轨的双运放。

可选型号：

- `MCP6002`
- `LMV358`
- `TLV9002`
- `SGM358`

不建议使用传统 `LM358` 作为首选，因为它虽然能单电源工作，但输入输出范围不如现代低压运放友好。

基础版使用非反相放大器：

```text
Av = 1 + Rf / Rin
```

推荐参数：

```text
Rin = 10kΩ
Rf = 100kΩ
Av = 1 + 100kΩ / 10kΩ = 11
```

如果麦克风信号太小，可以把 `Rf` 改为 `220kΩ`：

```text
Av = 1 + 220kΩ / 10kΩ = 23
```

放大电路思路：

```text
Mic_Out -- 1uF -- 运放 + 输入
                 |
                Vbias

运放 - 输入通过 Rin 接 Vbias
运放输出通过 Rf 反馈到 - 输入
```

注意：

- 运放电源脚旁边必须放 `100nF` 去耦电容。
- 麦克风和运放输入部分要远离 RGB LED 大电流走线。
- 模拟信号走线尽量短，不要从 LED 电源主干下面穿过。

## 6.6 包络检测电路

单片机 ADC 可以直接采样放大后的声音波形，但基础版更推荐先做包络检测，把快速变化的交流波形转换为随音量变化的慢速电压。

典型包络检测电路：

```text
运放输出 ---- 二极管 ---- Env_Out
                         |
                        1uF
                         |
                        GND

Env_Out ---- 100kΩ ---- GND
```

工作原理：

- 声音变大时，二极管导通，电容被快速充电。
- 声音变小时，电容通过电阻缓慢放电。
- `Env_Out` 就是一个随音量变化的直流电压。

RC 放电时间常数：

```text
τ = R × C
τ = 100kΩ × 1uF = 0.1s
```

这个响应速度适合做音乐节奏灯。若想反应更快，可以减小电容或电阻：

```text
R = 47kΩ, C = 1uF, τ = 0.047s
```

若想灯效更平滑，可以增大时间常数：

```text
R = 220kΩ, C = 1uF, τ = 0.22s
```

二极管选择：

- 基础版：`1N4148`
- 更灵敏：肖特基二极管，例如 `BAT54`

肖特基二极管正向压降低，更适合小信号整流。

## 6.7 单片机主控

推荐两种路线。

### 路线 A：使用现成开发板模块

适合第一次做 PCB。

推荐模块：

- `Seeed XIAO RP2040`
- `Seeed XIAO ESP32-C3`
- `Arduino Nano`
- `Raspberry Pi Pico` 模块

优点：

- 不需要自己设计晶振、复位、下载电路。
- 焊接和调试难度低。
- 失败风险小。

PCB 只需要给模块留排针或焊盘。

### 路线 B：直接使用裸芯片

适合有一定 PCB 和焊接基础后尝试。

可选芯片：

- `CH32V003`
- `STM32C011`
- `ATtiny1616`
- `ESP32-C3`

裸芯片方案需要额外考虑：

- 供电电容
- 下载接口
- 复位电路
- 时钟源
- 启动模式
- 固件烧录工具

本实践建议先使用路线 A。

## 6.8 按键和电位器

为了让作品更像完整产品，可以增加一个按键和一个电位器。

按键功能：

- 短按：切换灯效模式
- 长按：进入自动校准

电位器功能：

- 调节声音灵敏度

电位器连接：

```text
+5V
 |
10kΩ 电位器
 |
GND

中间抽头 -> 单片机 ADC
```

单片机读取电位器电压后，可以改变音量增益或触发阈值。

## 7. 三频段进阶方案

如果想让作品更像真正的频谱灯，可以把声音分成低频、中频、高频三路。

### 7.1 频段定义

建议频段：

| 频段 | 范围 | 对应声音 | 灯光颜色 |
| --- | --- | --- | --- |
| 低频 | 80Hz ~ 250Hz | 鼓点、低音 | 红色 |
| 中频 | 300Hz ~ 2kHz | 人声、旋律 | 绿色 |
| 高频 | 3kHz ~ 8kHz | 镲片、节奏细节 | 蓝色 |

### 7.2 实现方式

有两种实现方式。

方式一：模拟滤波

- 使用 RC 滤波或有源滤波器分出三路信号。
- 每一路经过整流和包络检测。
- 单片机读取三个 ADC 通道。

优点：

- 更贴近《电工电子学》课程内容。
- 能练习滤波器、运放和频率响应。

缺点：

- 参数调试较麻烦。
- 元件公差会影响实际效果。

方式二：软件频谱

- 单片机直接采样声音波形。
- 使用软件算法估算不同频段能量。
- 控制 RGB 灯显示。

优点：

- 硬件更简单。
- 效果可通过软件调整。

缺点：

- 需要一定编程基础。
- 对 ADC 采样率和程序性能有要求。

建议学习路线：

第一版先做“包络音量灯”，第二版再升级三频段。

## 9. 关键参数计算

## 9.1 USB-C CC 下拉电阻

普通 USB-C 取 5V 需要在 CC 引脚上接 Rd 下拉电阻。

常用值：

```text
Rcc = 5.1kΩ
```

连接：

```text
CC1 -> 5.1kΩ -> GND
CC2 -> 5.1kΩ -> GND
```

## 9.2 RGB 灯最大电流

假设使用 16 颗 WS2812B：

```text
单颗最大电流 = 60mA
总最大电流 = 16 × 60mA = 960mA
```

软件限制亮度为 30%：

```text
典型电流 = 960mA × 0.3 = 288mA
```

再加上单片机和运放电流，整板典型电流约 `300mA ~ 400mA`。

建议电源：

```text
5V 1A 可以运行
5V 2A 更稳妥
```

## 9.3 运放增益

非反相放大器：

```text
Av = 1 + Rf / Rin
```

基础参数：

```text
Rin = 10kΩ
Rf = 100kΩ
Av = 11
```

增强参数：

```text
Rin = 10kΩ
Rf = 220kΩ
Av = 23
```

如果后级信号容易饱和，就降低 `Rf`。如果声音太小，就增大 `Rf`。

## 9.4 包络检测时间常数

```text
τ = R × C
```

推荐：

```text
R = 100kΩ
C = 1uF
τ = 0.1s
```

效果：

- `τ` 小：反应快，灯光跳动明显，但可能抖动。
- `τ` 大：反应慢，灯光平滑，但节奏感变弱。

可以预留多个电容焊盘，方便调试：

- `0.47uF`
- `1uF`
- `2.2uF`

## 11. PCB 设计要求

## 11.1 板形建议

推荐做圆形板：

```text
直径：60 mm ~ 80 mm
层数：2 层
板厚：1.6 mm
铜厚：1 oz
最小线宽线距：0.15 mm 或按板厂能力设置
```

如果是第一次做板，建议不要追求过小尺寸。元件间距留宽一点，方便焊接和调试。

## 11.2 布局分区

建议按功能分区：

```text
          RGB 灯环区域
    +-----------------------+
    |   LED LED LED LED     |
    |                       |
    |  模拟前端     主控     |
    |  麦克风       模块     |
    |                       |
    | USB-C  电源滤波        |
    +-----------------------+
```

布局原则：

- USB-C 接口放板边，方便插线。
- 大电解电容靠近 USB-C 输入和 RGB 灯电源入口。
- RGB 灯沿外圈均匀摆放。
- 麦克风尽量放在板边或正面开孔位置，避免被外壳遮住。
- 麦克风和运放输入远离 RGB 灯电源线。
- 单片机放在中间或偏一侧，方便连线。

## 11.3 电源和地线

要求：

- 顶层和底层尽量铺 GND 铜。
- RGB 灯的 `+5V` 和 `GND` 走线要比普通信号线粗。
- USB-C 到 RGB 灯电源入口的路径要短而宽。
- 每颗 RGB 灯旁边放 `100nF` 电容。
- 运放电源脚旁边放 `100nF`，距离越近越好。

建议线宽：

| 走线类型 | 建议线宽 |
| --- | --- |
| 普通信号线 | 0.20 mm ~ 0.30 mm |
| ADC 模拟信号 | 0.20 mm ~ 0.30 mm，尽量短 |
| RGB 数据线 | 0.25 mm ~ 0.30 mm |
| LED 5V 主干 | 0.80 mm ~ 1.20 mm |
| GND 主干 | 尽量铺铜 |

## 11.4 模拟电路布局

模拟电路是本项目最容易受干扰的部分。

注意事项：

- 麦克风到运放输入的走线越短越好。
- `VBIAS` 节点要加电容滤波，不要从大电流区域穿过。
- `ENV_OUT` 到单片机 ADC 的走线不要贴近 RGB 数据线。
- 运放反馈电阻尽量靠近运放引脚。
- 包络检测电容和放电电阻靠近运放输出和 ADC 输入。

## 11.5 测试点设计

一定要预留测试点。没有测试点，调试会非常痛苦。

推荐测试点：

| 测试点 | 用途 |
| --- | --- |
| `TP_5V` | 测输入电压 |
| `TP_GND` | 示波器地夹 |
| `TP_VBIAS` | 测 2.5V 偏置 |
| `TP_MIC` | 测麦克风原始信号 |
| `TP_AMP` | 测运放输出 |
| `TP_ENV` | 测包络输出 |
| `TP_LED` | 测 RGB 数据 |

如果有示波器，调试这些节点可以直观看到声音信号变化。

## 12. 固件设计思路

基础固件逻辑：

```text
初始化 RGB LED
初始化 ADC
初始化按键

循环：
  读取 ENV_OUT
  读取灵敏度电位器
  对音量做平滑滤波
  自动估算环境噪声底
  计算灯光强度
  根据模式生成颜色
  刷新 RGB LED
```

## 12.1 音量归一化

ADC 读取值可能会受麦克风、音乐音量、运放增益影响。可以做简单归一化：

```text
volume_raw = ADC(ENV_OUT)
volume = volume_raw - noise_floor
if volume < 0:
    volume = 0
```

`noise_floor` 可以在开机前 2 秒采样平均得到。

## 12.2 平滑滤波

为了避免灯光抖动，可以做一阶低通滤波：

```text
smooth = smooth * 0.8 + volume * 0.2
```

如果想反应更快：

```text
smooth = smooth * 0.6 + volume * 0.4
```

如果想更柔和：

```text
smooth = smooth * 0.9 + volume * 0.1
```

## 12.3 灯效模式

建议至少实现三个模式。

模式 1：音量柱

- 音量越大，点亮灯珠数量越多。
- 适合验证电路是否正常。

模式 2：鼓点扩散

- 检测到音量突增时，从某个位置向两侧扩散。
- 视觉效果更明显。

模式 3：彩虹旋转

- 背景颜色缓慢旋转。
- 音量越大，整体亮度越高。

## 13. 调试流程

调试时不要一次性焊完所有器件再上电。建议分阶段进行。

### 13.1 焊接前检查

检查内容：

- USB-C 封装方向是否正确。
- RGB 灯珠方向是否一致。
- 运放电源脚和地脚是否接反。
- 电解电容极性是否正确。
- 单片机模块引脚是否对应。
- PCB 上是否有明显短路或断线。

### 13.2 电源测试

先不焊 RGB 灯和主控，或至少不插主控模块。

测试步骤：

1. 用万用表蜂鸣档测 `+5V` 和 `GND` 是否短路。
2. 插入 USB 5V 电源。
3. 测 `TP_5V` 是否约为 `5V`。
4. 测电源指示 LED 是否亮。
5. 摸一下电源区域是否异常发热。

### 13.3 偏置电压测试

测试：

```text
TP_VBIAS ≈ 2.5V
```

如果不是 2.5V，检查：

- 两个分压电阻是否都是 `100kΩ`
- 是否焊错位置
- `VBIAS` 是否被其他电路短接

### 13.4 麦克风和运放测试

如果有示波器：

- `TP_MIC` 应该能看到很小的声音波形。
- `TP_AMP` 应该能看到围绕 `2.5V` 上下变化的放大波形。
- 对着麦克风拍手，波形幅度应明显增大。

如果只有万用表：

- `TP_AMP` 直流平均值应接近 `2.5V`。
- `TP_ENV` 在安静时较低，拍手或播放音乐时升高。

### 13.5 RGB LED 测试

先写一个最简单的测试程序：

- 点亮第 1 颗红色
- 点亮第 2 颗绿色
- 点亮第 3 颗蓝色
- 全部低亮度白色

如果只有前几颗亮，检查：

- 第一颗不亮：检查数据线、供电、灯珠方向。
- 从某一颗之后不亮：检查那一颗的 DOUT 到下一颗 DIN。
- 颜色错误：检查程序颜色顺序，可能是 GRB 而不是 RGB。

### 13.6 整机联调

完整测试：

1. 安静环境下观察 ADC 值。
2. 播放音乐观察 ADC 值变化。
3. 调整电位器，让灯光灵敏度合适。
4. 限制最大亮度，避免 USB 供电过载。
5. 连续运行 30 分钟，检查芯片和灯珠温度。

## 14. 常见问题

### 14.1 灯珠闪烁或复位

可能原因：

- 电源电流不够。
- 输入电容太小。
- LED 亮度过高。
- 5V 和 GND 走线太细。

解决：

- 使用 `5V 2A` 电源。
- 增加 `470uF ~ 1000uF` 输入电容。
- 软件限制亮度到 30% 以下。
- PCB 加粗电源线并铺地。

### 14.2 麦克风没有反应

可能原因：

- 麦克风极性接反。
- 偏置电阻没有接到 5V。
- 交流耦合电容接错。
- 运放输入偏置没有接好。

解决：

- 测 `MIC_OUT` 直流电压。
- 测 `VBIAS` 是否约 2.5V。
- 用示波器或万用表观察 `ENV_OUT`。

### 14.3 灯光一直满亮

可能原因：

- 运放输出饱和。
- 包络电容充电后无法放电。
- ADC 读取引脚接错。
- 软件阈值过低。

解决：

- 降低运放增益。
- 检查包络放电电阻是否焊接。
- 打印 ADC 数值确认范围。
- 增大软件噪声阈值。

### 14.4 灯光反应太慢

可能原因：

- 包络时间常数太大。
- 软件滤波太强。

解决：

- 把包络电容从 `1uF` 改为 `0.47uF`。
- 把放电电阻从 `100kΩ` 改为 `47kΩ`。
- 降低软件平滑系数。

## 17. 建议学习重点

做这个项目时，不要只追求灯亮。重点是把理论和实物对应起来。

建议重点观察：

- 电容为什么能隔直流、通交流。
- 运放为什么需要中点偏置。
- 反馈电阻如何决定放大倍数。
- RC 时间常数如何影响灯光响应速度。
- 大电流 LED 为什么会干扰模拟信号。
- PCB 中地线和电源线为什么不能随便画。
- 测试点为什么能大幅降低调试难度。

如果能把这些问题解释清楚，这个项目就不仅是一个炫酷小灯，而是一次完整的电工电子学实践训练。
