# 组合变形计算程序实现思路

## 1. 为什么要扩展到组合变形

当前 `大作业v1` 程序主要解决的是梁在横向载荷作用下的平面弯曲问题，计算内容包括支座反力、剪力、弯矩、弯曲正应力和挠度。这已经覆盖了材料力学中“梁弯曲”的核心内容，但算例相对标准，例如简支梁跨中集中力、悬臂梁端部集中力、局部均布载荷等。

如果想让大作业显得更完整、更有专题研究深度，可以把程序扩展到“组合变形”问题。组合变形比单一弯曲更接近工程结构的真实受力状态，例如：

1. 偏心拉压：轴向拉压 + 弯曲；
2. 斜弯曲：两个主惯性平面内的弯曲叠加；
3. 弯扭组合：弯曲正应力 + 扭转切应力；
4. 拉压、弯曲、扭转共同作用下的强度校核。

这样程序不仅能画内力图，还能进一步计算危险截面的应力状态、主应力、第三强度理论或第四强度理论等效应力，使算例复杂度明显提升。

## 2. 建议优先实现的组合变形类型

不建议一开始直接实现所有三维杆件问题，否则程序复杂度会快速上升。更稳妥的方式是分阶段扩展。

### 2.1 第一阶段：轴向力 + 单向弯曲

这是最容易在现有程序基础上扩展的组合变形类型。

典型问题：

1. 悬臂梁端部受到竖向力，同时受到轴向拉力或压力；
2. 简支梁承受横向载荷，同时受到轴向拉力；
3. 偏心压力柱，偏心载荷等效为轴向力和弯矩。

计算公式：

```text
sigma(x, y) = N(x) / A - M(x) y / I
```

若只关心截面上下边缘，则：

```text
sigma_top = N / A - M yMax / I
sigma_bottom = N / A + M yMax / I
```

这个阶段只需要在原有弯曲程序中增加轴力 `N(x)` 和截面面积 `A`，实现难度较低。

### 2.2 第二阶段：双向弯曲，也就是斜弯曲

双向弯曲适合体现组合变形的“复杂性”。

典型问题：

1. 矩形截面悬臂梁端部受到斜向集中力；
2. 梁同时受到竖向载荷和水平横向载荷；
3. 工程中受风荷载和竖向荷载共同作用的杆件。

如果截面主惯性轴为 `y`、`z`，弯矩分量为 `My`、`Mz`，则截面任意点应力为：

```text
sigma(x, y, z) = N / A + Mz * y / Iz - My * z / Iy
```

程序可以对截面四个角点计算正应力，取绝对值最大的点作为危险点。对于矩形截面，这种方法直观、容易解释，也适合写入说明书。

### 2.3 第三阶段：弯曲 + 扭转

弯扭组合是材料力学组合变形中很经典的一类问题。

典型问题：

1. 圆轴一端固定，另一端受到横向力和扭矩；
2. 传动轴上齿轮同时产生弯矩和扭矩；
3. 悬臂圆杆端部受到偏置载荷，产生弯矩和扭矩。

弯曲正应力：

```text
sigma = M c / I
```

扭转切应力：

```text
tau = T c / J
```

其中 `c` 为圆截面半径，`I` 为截面惯性矩，`J` 为极惯性矩。

危险点处可计算主应力：

```text
sigma_1 = sigma / 2 + sqrt((sigma / 2)^2 + tau^2)
sigma_2 = sigma / 2 - sqrt((sigma / 2)^2 + tau^2)
```

也可以计算等效应力：

第三强度理论：

```text
sigma_eq3 = sqrt(sigma^2 + 4 tau^2)
```

第四强度理论：

```text
sigma_eq4 = sqrt(sigma^2 + 3 tau^2)
```

这个阶段的理论内容更丰富，非常适合做一个“复杂算例”。

## 3. 建议的新程序总体结构

为了不破坏现有 `大作业v1`，建议新建一个版本文件夹，例如：

```text
大作业v2/
```

其中保留原来的弯曲计算函数，同时增加组合变形相关函数。

建议文件结构：

```text
大作业v2/
  mainCombined.m
  runCombinedExamples.m
  calcReaction.m
  calcInternalForce.m
  calcDeflection.m
  calcSectionStress.m
  calcCombinedStress.m
  calcEquivalentStress.m
  sectionProperties.m
  plotCombinedResult.m
  beamGetField.m
  beamLoadResultants.m
```

其中：

| 文件名 | 作用 |
| --- | --- |
| `mainCombined.m` | 组合变形主程序入口 |
| `runCombinedExamples.m` | 组合变形典型算例集合 |
| `calcSectionStress.m` | 计算截面上若干点的正应力和切应力 |
| `calcCombinedStress.m` | 计算拉压、弯曲、扭转叠加后的应力状态 |
| `calcEquivalentStress.m` | 计算主应力、第三强度理论、第四强度理论等效应力 |
| `sectionProperties.m` | 根据截面类型自动生成 `A`、`Iy`、`Iz`、`J`、危险点坐标 |
| `plotCombinedResult.m` | 绘制轴力、弯矩、扭矩、危险点应力和等效应力图 |

## 4. 数据结构设计

### 4.1 梁参数 `beam`

原程序中的 `beam` 可以继续使用，但要增加截面参数。

```matlab
beam.L = 2.0;
beam.E = 210e9;
beam.G = 80e9;
beam.n = 1000;
```

### 4.2 截面参数 `section`

建议把截面参数独立成一个结构体。

矩形截面：

```matlab
section.type = "rectangle";
section.b = 0.06;
section.h = 0.10;
```

圆截面：

```matlab
section.type = "circle";
section.d = 0.05;
```

由 `sectionProperties.m` 自动计算：

```matlab
section.A
section.Iy
section.Iz
section.J
section.points
```

其中 `section.points` 用于保存需要检查的危险点坐标。例如矩形截面可以检查四个角点：

```matlab
section.points = [
    yMax,  zMax;
   -yMax,  zMax;
   -yMax, -zMax;
    yMax, -zMax
];
```

### 4.3 载荷参数 `loads`

原程序的横向载荷结构可以保留，同时新增轴向力和扭矩。

```matlab
loads(1).type = "point_y";
loads(1).P = -1000;
loads(1).x = beam.L;

loads(2).type = "axial";
loads(2).N = 5000;
loads(2).x = beam.L;

loads(3).type = "torque";
loads(3).T = 120;
loads(3).x = beam.L;
```

为避免命名混乱，建议把载荷方向明确写进类型中：

| 类型 | 含义 |
| --- | --- |
| `axial` | 轴向拉压力 |
| `point_y` | 沿 `y` 方向的横向集中力 |
| `point_z` | 沿 `z` 方向的横向集中力 |
| `udl_y` | 沿 `y` 方向的均布载荷 |
| `udl_z` | 沿 `z` 方向的均布载荷 |
| `moment_y` | 绕 `y` 轴的集中弯矩 |
| `moment_z` | 绕 `z` 轴的集中弯矩 |
| `torque` | 绕杆轴的扭矩 |

## 5. 核心计算流程

组合变形主程序可以按以下步骤实现：

```text
1. 输入梁、截面、支座、载荷参数
2. 根据截面类型计算 A、Iy、Iz、J 和危险点坐标
3. 沿杆长方向离散 x
4. 分别计算：
   N(x)  轴力
   Vy(x) y 方向剪力
   Vz(x) z 方向剪力
   My(x) 绕 y 轴弯矩
   Mz(x) 绕 z 轴弯矩
   T(x)  扭矩
5. 对每个 x 位置、每个截面危险点计算应力
6. 找出最大拉应力、最大压应力、最大切应力、最大等效应力
7. 输出危险截面位置和危险点坐标
8. 绘制内力图和应力图
```

关键是不要把所有应力都混在一个函数里。推荐分层：

1. `calcInternalForce3D` 只负责内力；
2. `calcSectionStress` 只负责截面点应力；
3. `calcEquivalentStress` 只负责强度理论；
4. `plotCombinedResult` 只负责绘图。

这样程序结构会比直接堆在 `main.m` 中清楚得多。

## 6. 应力计算公式组织

对某一截面位置 `x(i)`，已知：

```text
N, My, Mz, T
```

对截面某个点 `(y, z)`，正应力可以写为：

```text
sigma = N / A + Mz * y / Iz - My * z / Iy
```

如果考虑圆轴扭转，危险点切应力可以写为：

```text
tau = T * r / J
```

如果只在圆截面外缘检查，可取：

```text
r = d / 2
```

对应的等效应力为：

```text
sigma_eq3 = sqrt(sigma^2 + 4 * tau^2)
sigma_eq4 = sqrt(sigma^2 + 3 * tau^2)
```

程序中可以保存：

```matlab
stress.sigma(i, p)
stress.tau(i, p)
stress.sigmaEq3(i, p)
stress.sigmaEq4(i, p)
```

其中 `i` 表示梁长方向离散点，`p` 表示截面检查点。

## 7. 推荐复杂算例

### 7.1 算例 A：偏心拉压杆

问题描述：

一根矩形截面短杆，受到偏心压力 `P`，偏心距为 `e`。偏心压力可等效为轴向压力和弯矩：

```text
N = -P
M = P e
```

计算内容：

1. 截面上下边缘正应力；
2. 中性轴位置；
3. 是否出现拉应力区；
4. 最大压应力位置。

这个算例适合说明“轴向压缩 + 弯曲”的叠加。

### 7.2 算例 B：矩形截面悬臂梁斜向受力

问题描述：

一根矩形截面悬臂梁，端部受到斜向力 `P`，该力分解为 `Py` 和 `Pz`，分别产生两个方向的弯矩。

```text
Py = P cos(alpha)
Pz = P sin(alpha)
```

计算内容：

1. 绕 `y` 轴和绕 `z` 轴的弯矩；
2. 截面四角点正应力；
3. 最大拉应力和最大压应力；
4. 危险点在截面哪个角。

这个算例比单向弯曲更复杂，但仍然容易解释，适合作为说明书中的主要复杂算例。

### 7.3 算例 C：圆轴弯扭组合

问题描述：

一根圆截面悬臂轴，左端固定，右端受到横向力 `P` 和扭矩 `T`。横向力产生弯矩，扭矩产生切应力。

计算内容：

1. 固定端最大弯矩；
2. 固定端最大弯曲正应力；
3. 扭转切应力；
4. 主应力；
5. 第三强度理论和第四强度理论等效应力；
6. 与许用应力比较进行强度校核。

这个算例最能体现组合变形和强度理论，建议作为升级后说明书的重点算例。

## 8. 最推荐的大作业升级路线

如果目标是“快速增强复杂度，同时保证能写清楚、能调通”，推荐路线如下：

1. 保留 `大作业v1` 作为梁弯曲基础版本；
2. 新建 `大作业v2`；
3. 先实现截面属性函数 `sectionProperties.m`；
4. 实现 `calcCombinedStress.m`，先支持 `N + My + Mz`；
5. 增加矩形截面斜弯曲算例；
6. 再实现 `T` 和 `calcEquivalentStress.m`；
7. 增加圆轴弯扭组合算例；
8. 最后更新说明书，把原来的简单梁弯曲算例改成“基础算例 + 组合变形复杂算例”。

## 9. 可能的程序主算例设计

建议最终主算例使用“圆轴弯扭组合”，因为它包含弯曲、扭转和强度理论，展示效果最好。

示例参数：

```text
圆轴长度 L = 1.2 m
直径 d = 50 mm
弹性模量 E = 210 GPa
切变模量 G = 80 GPa
端部横向力 P = 1500 N
端部扭矩 T = 300 N*m
许用应力 [sigma] = 160 MPa
```

理论结果可用于校核：

```text
Mmax = P L = 1800 N*m
I = pi d^4 / 64
J = pi d^4 / 32
sigma = Mmax (d/2) / I
tau = T (d/2) / J
sigma_eq4 = sqrt(sigma^2 + 3 tau^2)
```

程序输出：

```text
最大弯矩位置：固定端
最大弯曲正应力：固定端外缘
最大扭转切应力：固定端外缘
第四强度理论等效应力
是否满足强度条件
```

这个算例比原来的简支梁算例更有工程感，也更符合“专题研究”的要求。

## 10. 实现难点与注意事项

1. 坐标和符号必须统一。尤其是 `My`、`Mz` 对截面点 `(y,z)` 的正应力符号，不统一会导致危险点判断错误。
2. 矩形截面和圆截面的检查点不同。矩形截面适合检查四个角点，圆截面适合检查外缘最大应力点。
3. 扭转切应力方向较复杂。如果只做强度校核，可以先计算最大切应力大小，不必完整绘制截面切应力方向。
4. 原程序是二维梁弯曲，扩展到斜弯曲时需要区分 `y` 向载荷和 `z` 向载荷。
5. 如果要计算挠度，双向弯曲需要分别计算两个方向的挠度；如果本阶段重点是组合应力，可以先不扩展挠度。
6. 组合变形说明书中要明确“应力叠加适用于线弹性、小变形条件”。

## 11. 结论

升级后的程序不应简单增加几个更大的载荷，而应从“单一弯曲内力计算”扩展到“组合内力和危险点应力分析”。最合理的实现路径是：

```text
轴向力 + 弯曲
    -> 双向弯曲
    -> 弯曲 + 扭转
    -> 等效应力与强度校核
```

其中，圆轴弯扭组合算例最适合作为最终复杂算例；矩形截面斜弯曲算例适合作为过渡算例。这样既能体现材料力学组合变形的理论内容，也能让 Matlab 程序功能明显比当前版本更完整。
