# 空间应力状态主应力大小及方向分析计算说明书

## 1. 选题名称

**基于 Matlab 的空间应力状态主应力大小及方向分析与动画演示**

本专题围绕材料力学中“应力状态分析”和“主应力、主方向求解”展开。通过 Matlab 编写计算程序，对一点处的三维空间应力状态进行主应力分析，并结合三维应力单元体、主方向箭头、三维莫尔圆和动画演示，使抽象的应力变换过程更加直观。

## 2. 选题背景与意义

在材料力学中，构件上一点处的受力状态通常并不只是简单的单向拉伸或压缩，而可能同时存在三个方向的正应力和多个方向的切应力。例如轴类零件、连接件、压力容器局部区域、复杂支架和机械结构节点处，都可能处于空间应力状态。

直接观察原始坐标系下的应力分量，往往难以判断材料最危险的受力方向。因此需要进行应力状态分析，求出主应力、主方向和最大切应力。主应力代表某一方向截面上没有切应力时的正应力极值，主方向则给出这些特殊截面的空间方向。

本专题的意义在于：

1. 将空间应力状态的理论计算过程程序化。
2. 用 Matlab 自动求解主应力和主方向，避免手工求解三次特征方程。
3. 通过三维图形和动画展示应力单元体旋转到主方向的过程。
4. 通过三维莫尔圆展示不同主应力之间的正应力和切应力变化关系。
5. 体现材料力学理论、矩阵计算和科学可视化的结合。

## 3. 作业要求对应关系

作业要求中给出的参考方向之一为：

> 平面或空间应力状态应力分析，主应力大小及方向的研究和讨论，发挥编程特长，加入动画演示，使结果更直观更容易理解。

本专题正是围绕该方向展开。程序完成了以下内容：

1. 输入空间应力状态的 6 个独立应力分量。
2. 自动构造三维应力张量。
3. 求解三个主应力及其对应主方向。
4. 计算方向余弦、方向角、应力不变量、最大切应力和 Von Mises 等效应力。
5. 绘制原始应力单元体和主应力坐标系下的应力单元体。
6. 绘制三维主方向箭头。
7. 绘制三维莫尔圆。
8. 加入应力单元体旋转到主方向的动画演示。
9. 加入莫尔圆上动点演示，展示截面应力变化过程。

## 4. 理论基础

### 4.1 空间应力状态表示

一点处的一般空间应力状态可用二阶对称应力张量表示：

```text
        [ sigma_x   tau_xy   tau_zx ]
sigma = [ tau_xy    sigma_y  tau_yz ]
        [ tau_zx    tau_yz   sigma_z]
```

其中：

```text
sigma_x, sigma_y, sigma_z
```

为三个坐标面上的正应力；

```text
tau_xy, tau_yz, tau_zx
```

为切应力分量。

由于静力平衡要求互等切应力相等，因此应力张量为对称矩阵。

### 4.2 主应力和主方向

若某一截面上的切应力为零，则该截面法线方向称为主方向，该截面上的正应力称为主应力。设主方向单位向量为 `n`，主应力为 `lambda`，则有：

```text
sigma * n = lambda * n
```

这实际上是矩阵特征值问题。三个特征值就是三个主应力：

```text
sigma1, sigma2, sigma3
```

对应的三个特征向量就是三个主方向。程序中按大小排序：

```text
sigma1 >= sigma2 >= sigma3
```

### 4.3 应力不变量

空间应力状态在坐标旋转下，其应力张量分量会改变，但三个应力不变量保持不变：

```text
I1 = sigma_x + sigma_y + sigma_z
```

```text
I2 = sigma_x sigma_y + sigma_y sigma_z + sigma_z sigma_x
     - tau_xy^2 - tau_yz^2 - tau_zx^2
```

```text
I3 = det(sigma)
```

主应力也满足：

```text
I1 = sigma1 + sigma2 + sigma3
```

```text
I2 = sigma1 sigma2 + sigma2 sigma3 + sigma3 sigma1
```

```text
I3 = sigma1 sigma2 sigma3
```

因此，应力不变量可以用于检查计算结果是否正确。

### 4.4 最大切应力

空间应力状态下的最大切应力为：

```text
tau_max = (sigma1 - sigma3) / 2
```

它对应三维莫尔圆中最大圆的半径。

### 4.5 Von Mises 等效应力

对于塑性屈服或强度判断，常使用第四强度理论，即 Von Mises 等效应力：

```text
sigma_v = sqrt(1/2 * [ (sigma1 - sigma2)^2
                     + (sigma2 - sigma3)^2
                     + (sigma3 - sigma1)^2 ])
```

虽然本专题主要研究主应力大小和方向，但加入 Von Mises 等效应力有助于进一步进行强度分析。

### 4.6 三维莫尔圆

空间应力状态下，三个主应力可组成三组莫尔圆：

```text
sigma1 - sigma2 圆
sigma2 - sigma3 圆
sigma1 - sigma3 圆
```

圆心和半径分别为：

```text
C_ij = (sigma_i + sigma_j) / 2
R_ij = |sigma_i - sigma_j| / 2
```

其中最大莫尔圆的半径即最大切应力。

## 5. 程序设计

### 5.1 程序总体结构

程序文件夹为：

```text
stress3d_principal_animation/
```

主要文件如下：

| 文件 | 作用 |
| --- | --- |
| `mainStress3D.m` | 主程序入口，定义算例、调用计算和绘图动画 |
| `stressTensorFromComponents.m` | 根据 6 个应力分量构造应力张量 |
| `calcPrincipalStress.m` | 计算主应力、主方向和相关应力量 |
| `printPrincipalResult.m` | 在命令行输出计算结果 |
| `plotStressCube.m` | 绘制应力单元体图 |
| `drawStressCube.m` | 底层绘制函数，绘制立方体和面力箭头 |
| `plotPrincipalDirections.m` | 绘制三维主方向箭头 |
| `plotMohr3D.m` | 绘制三维莫尔圆 |
| `animatePrincipalRotation.m` | 演示应力单元体旋转到主方向 |
| `animateMohrCircle.m` | 演示莫尔圆上应力状态变化 |
| `rotationInterp.m` | 进行旋转矩阵插值 |
| `transformStressTensor.m` | 对应力张量进行坐标变换 |
| `runStressExamples.m` | 运行多个典型算例 |

### 5.2 主程序流程

主程序 `mainStress3D.m` 的计算流程为：

```text
1. 输入 sigma_x, sigma_y, sigma_z, tau_xy, tau_yz, tau_zx
2. 构造应力张量 S
3. 调用 eig 求解特征值和特征向量
4. 将主应力按从大到小排序
5. 计算方向余弦、方向角、应力不变量和最大切应力
6. 输出数值结果
7. 绘制原始应力单元体
8. 绘制主应力坐标系下的应力单元体
9. 绘制主方向箭头
10. 绘制三维莫尔圆
11. 播放应力单元体旋转动画
12. 播放莫尔圆动点动画
```

### 5.3 主应力计算函数

核心函数为 `calcPrincipalStress.m`。其主要语句为：

```matlab
[V, D] = eig(S);
principal = diag(D);
[principal, order] = sort(principal, "descend");
V = V(:, order);
```

其中：

```text
D 的对角线元素为主应力
V 的列向量为对应主方向
```

排序后：

```text
V(:,1) 对应 sigma1
V(:,2) 对应 sigma2
V(:,3) 对应 sigma3
```

### 5.4 应力单元体绘图

程序用一个透明立方体表示应力单元体，并在六个面上绘制面力箭头。某一面外法线为 `n` 时，该面上的应力矢量为：

```text
t = sigma * n
```

程序根据 `t` 的方向和大小绘制箭头，从而直观表示该面上的正应力和切应力。

### 5.5 主方向旋转动画

主方向矩阵 `V` 的三列为主方向单位向量。程序将原始坐标系逐渐旋转到主方向坐标系，并在每一帧中计算变换后的应力张量：

```text
S_local = R^T * S * R
```

动画开始时：

```text
R = I
```

表示原始坐标系；动画结束时：

```text
R = V
```

表示主应力坐标系。此时应力张量变成近似对角矩阵，非对角切应力分量趋近于零。这一过程直观说明了“主平面上切应力为零”。

### 5.6 莫尔圆动画

三维莫尔圆动画在三个莫尔圆上设置动点。动点沿圆周运动时，可以直观展示不同截面方向下正应力和切应力的变化范围。最大圆的半径对应最大切应力。

## 6. 典型算例

### 6.1 输入应力状态

默认算例采用一般空间应力状态，单位为 MPa：

```text
sigma_x = 80
sigma_y = 40
sigma_z = -20
tau_xy  = 30
tau_yz  = 15
tau_zx  = 25
```

对应应力张量为：

```text
        [ 80   30   25 ]
S   =   [ 30   40   15 ]  MPa
        [ 25   15  -20 ]
```

该算例同时包含三个方向正应力和三个方向切应力，属于一般三维应力状态，适合验证程序的主应力分析功能。

### 6.2 主应力计算结果

程序计算得到三个主应力为：

```text
sigma1 = 102.954 MPa
sigma2 = 23.981 MPa
sigma3 = -26.935 MPa
```

可以看出，原始坐标系下最大正应力分量为 `80 MPa`，但经过应力状态分析后，实际最大主应力达到约 `102.954 MPa`。这说明直接观察坐标方向正应力可能低估危险程度。

### 6.3 主方向计算结果

三个主方向的方向余弦矩阵为：

```text
        [  0.855958    0.480803    0.190169 ]
V   =   [  0.462822   -0.876454    0.132755 ]
        [  0.230504   -0.025618   -0.972734 ]
```

其中第一列对应 `sigma1` 的方向，第二列对应 `sigma2` 的方向，第三列对应 `sigma3` 的方向。

主方向与 `x, y, z` 轴的夹角为：

```text
        [  31.134    61.262    79.037 ]
        [  62.431   151.218    82.371 ]
        [  76.673    91.468   166.590 ]  deg
```

例如第一主方向与 `x` 轴夹角约为 `31.134 deg`，与 `y` 轴夹角约为 `62.431 deg`，与 `z` 轴夹角约为 `76.673 deg`。

### 6.4 应力不变量和派生量

计算得到：

```text
I1 = 100.000
I2 = -950.000
I3 = -66500.000
```

最大切应力为：

```text
tau_max = (sigma1 - sigma3) / 2 = 64.944 MPa
```

平均应力为：

```text
sigma_m = 33.333 MPa
```

Von Mises 等效应力为：

```text
sigma_v = 113.358 MPa
```

八面体切应力为：

```text
tau_oct = 53.437 MPa
```

这些结果可用于进一步的强度判断。

## 7. 图形与动画结果说明

### 7.1 原始应力单元体

程序首先绘制原始坐标系下的应力单元体。立方体的六个面上绘有应力矢量箭头。箭头方向表示该面上的面力方向，箭头大小与应力分量大小有关。

由于原始应力张量中存在 `tau_xy`、`tau_yz` 和 `tau_zx`，因此在原始应力单元体上可以观察到明显的切向箭头，说明各坐标面上不仅有正应力，还有切应力。

### 7.2 主应力坐标系下的应力单元体

第二个应力单元体是在主应力方向下绘制的。此时应力张量理论上为对角矩阵：

```text
        [ sigma1    0       0    ]
S_p =   [   0     sigma2    0    ]
        [   0       0     sigma3 ]
```

图中各面上的应力箭头主要沿面法线方向，切向分量消失，体现了主平面上切应力为零的特点。

### 7.3 主方向箭头图

主方向箭头图用三条不同颜色的箭头表示三个主方向。每个箭头旁标注对应主应力值。该图能直观显示主应力方向与原始 `x, y, z` 坐标轴并不重合。

### 7.4 三维莫尔圆

程序绘制三个莫尔圆：

```text
sigma1-sigma2 圆
sigma2-sigma3 圆
sigma1-sigma3 圆
```

其中最大圆为 `sigma1-sigma3` 圆，其半径为：

```text
64.944 MPa
```

即最大切应力。

### 7.5 主方向旋转动画

动画展示应力单元体从原始方向逐渐旋转到主方向的过程。随着旋转进行，程序实时计算当前坐标系下的应力张量，并在标题中显示非对角切应力分量的最大值。

动画结束时，非对角切应力分量趋近于零，说明已经到达主应力坐标系。

### 7.6 莫尔圆动点动画

莫尔圆动画在三个莫尔圆上设置动点，动点绕圆周运动，表示截面方向变化时对应的正应力和切应力变化。该动画有助于理解主应力和最大切应力在莫尔圆中的几何意义。

## 8. 多算例验证

程序还提供 `runStressExamples.m`，包含以下典型应力状态：

1. 一般三维应力状态。
2. 平面应力加切应力。
3. 纯剪切应力状态。
4. 静水拉伸应力状态。

这些算例可以用于验证程序对不同应力状态的适用性。例如纯剪切状态下，主应力应呈现一拉一压；静水拉伸状态下，三个主应力相等，任意方向均可作为主方向。

## 9. 结果讨论

通过默认算例可以得到以下认识：

1. 空间应力状态下，最大主应力不一定等于原始坐标系中最大的正应力分量。
2. 切应力会显著影响主应力大小和主方向。
3. 主方向通常与原始坐标轴不重合，需要通过特征向量确定。
4. 在主应力坐标系下，应力张量变为对角形式，说明主平面上没有切应力。
5. 三维莫尔圆能够清楚表示主应力与最大切应力之间的关系。
6. 动画演示比静态公式更直观，能帮助理解应力张量坐标变换的物理意义。

本程序没有局限于某一个特定构件，而是面向材料力学中更一般的“一点应力状态分析”。因此它可以作为后续复杂结构强度分析的基础模块。

## 10. 程序使用说明

进入文件夹：

```text
stress3d_principal_animation
```

在 Matlab 命令行运行：

```matlab
mainStress3D
```

如需修改算例，只需修改 `mainStress3D.m` 开头的输入参数：

```matlab
stress.sigmaX = 80;
stress.sigmaY = 40;
stress.sigmaZ = -20;
stress.tauXY = 30;
stress.tauYZ = 15;
stress.tauZX = 25;
```

如不想播放动画，可将：

```matlab
settings.playAnimations = true;
```

改为：

```matlab
settings.playAnimations = false;
```

如需改变动画速度和帧数，可修改：

```matlab
settings.frameCount = 80;
settings.pauseTime = 0.03;
```
