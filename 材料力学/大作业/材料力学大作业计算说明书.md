# 材料力学专题研究计算说明书

## 1. 选题说明

本次材料力学专题研究的题目为：基于 Matlab 的梁弯曲内力、应力与挠度计算程序设计。

题目要求如下图所示：

![assignment](./assignment.jpg)

材料力学课程中，梁的弯曲问题是最常见的结构力学问题之一。对于简支梁、悬臂梁、外伸梁等结构，在受到集中力、集中力偶、均布载荷和线性分布载荷作用时，通常需要计算支座反力、剪力、弯矩、弯曲正应力和挠度。若完全采用手算方法，需要分段建立方程，过程较繁琐，而且容易在载荷分段、符号约定和边界条件处理中出错。

因此，本程序利用 Matlab 编写通用计算工具，将材料力学中的静力平衡、截面法、弯曲正应力公式和 Euler-Bernoulli 梁挠曲线方程结合起来，实现梁弯曲问题的自动计算和绘图。程序源文件存放在 `大作业v1` 文件夹中。

## 2. 程序功能说明

程序主要完成以下功能：

1. 输入梁的几何参数和材料参数，包括梁长 `L`、弹性模量 `E`、截面惯性矩 `I`、截面边缘到中性轴的最大距离 `yMax` 和离散计算点数 `n`。
2. 输入支座类型和支座位置，当前支持简支梁、悬臂梁和外伸梁。
3. 输入载荷信息，当前支持集中力、集中力偶、均布载荷和线性分布载荷。
4. 根据整体静力平衡方程计算支座反力。
5. 沿梁长方向离散，计算每个位置处的剪力 `V(x)` 和弯矩 `M(x)`。
6. 根据弯曲正应力公式计算梁截面边缘最大正应力。
7. 根据梁挠曲线微分方程，采用数值积分方法计算转角和挠度。
8. 输出关键计算结果，并绘制载荷示意图、剪力图、弯矩图、正应力图和挠度曲线。

## 4. 基本假设与符号约定

程序采用以下基本假设：

1. 梁为等截面直梁，材料均匀、连续、各向同性。
2. 梁处于线弹性范围内，满足胡克定律。
3. 梁满足小变形假设。
4. 横截面变形后仍保持平面，即采用平截面假设。
5. 不考虑剪切变形对挠度的影响，采用 Euler-Bernoulli 梁理论。

程序符号约定如下：

1. 取梁左端为坐标原点，沿梁轴线向右为 `x` 轴正方向。
2. 竖直向上的集中力和支座反力取正，竖直向下的载荷取负。
3. 分布载荷强度 `q` 也按竖直向上为正，因此常见向下均布载荷取负值。
4. 剪力和弯矩由截面左侧所有外力累加得到。

## 5. 理论计算方法

### 5.1 支座反力计算

对于简支梁和外伸梁，设两个支座位置分别为 `xA`、`xB`，反力分别为 `RA`、`RB`。将外载荷等效为若干集中力 `Fi`、作用位置 `xi` 和集中力偶 `Mj` 后，整体平衡方程为：

```text
RA + RB + sum(Fi) = 0
RB(xB - xA) + sum[Fi(xi - xA)] - sum(Mj) = 0
```

因此：

```text
RB = -{sum[Fi(xi - xA)] - sum(Mj)} / (xB - xA)
RA = -sum(Fi) - RB
```

对于左端固定悬臂梁，固定端反力和固定端弯矩由：

```text
RA + sum(Fi) = 0
MA + RA(L - xA) + sum[Fi(L - xi)] + sum(Mj) = 0
```

确定。程序中固定端弯矩 `MA` 的取值使自由端内弯矩满足零边界条件。

### 5.2 载荷等效处理

集中力可直接参与平衡方程。均布载荷和线性分布载荷先转化为等效集中力。

对于作用在 `[a,b]` 区间内的均布载荷 `q`：

```text
F = q(b - a)
xF = (a + b) / 2
```

对于线性分布载荷，设起点强度为 `q1`，终点强度为 `q2`，作用长度为 `l = b - a`，则：

```text
F = (q1 + q2)l / 2
```

合力作用点由载荷图形的一次矩确定。

### 5.3 剪力与弯矩计算

程序沿梁长方向生成离散坐标：

```matlab
x = linspace(0, beam.L, beam.n);
```

然后按照截面左侧外力累加的方式计算剪力和弯矩。集中力 `P` 作用在 `xP` 时，对 `x >= xP` 的截面产生：

```text
Delta V = P
Delta M = P(x - xP)
```

集中力偶 `M0` 作用在 `xM` 时，不改变剪力，只使 `x >= xM` 的弯矩发生突变：

```text
Delta M = M0
```

均布载荷 `q` 作用在 `[x1,x2]` 区间内时，设某截面左侧已经包含的有效载荷长度为 `lx`，则其贡献为：

```text
Delta V = q lx
Delta M = q lx (x - x1 - lx/2)
```

这种处理方式避免了手动分段列式，适用于多个载荷叠加的情况。

### 5.4 弯曲正应力计算

根据材料力学弯曲正应力公式：

```text
sigma = M y / I
```

程序关注截面边缘最大正应力，因此取：

```text
sigma_max(x) = |M(x)| yMax / I
```

其中 `yMax` 为截面边缘到中性轴的最大距离，`I` 为截面对中性轴的惯性矩。

### 5.5 挠度与转角计算

根据 Euler-Bernoulli 梁理论：

```text
w''(x) = M(x) / EI
```

程序先由弯矩数组得到曲率数组，再用梯形积分 `cumtrapz` 积分两次：

```matlab
curvature = M ./ (beam.E * beam.I);
theta0 = cumtrapz(x, curvature);
deflection0 = cumtrapz(x, theta0);
```

数值积分后还需加入两个积分常数。对于简支梁和外伸梁，程序利用两个支座处挠度为零的边界条件：

```text
w(xA) = 0
w(xB) = 0
```

对于左端固定悬臂梁，程序利用固定端转角和挠度均为零的边界条件：

```text
theta(xA) = 0
w(xA) = 0
```

由此修正转角和挠度曲线，使其满足支座约束。

## 6. 主程序算例

`main.m` 中设置的算例如下：

| 参数 | 数值 |
| --- | --- |
| 梁长 `L` | 6.0 m |
| 弹性模量 `E` | 210 GPa |
| 截面惯性矩 `I` | 8.0e-6 m^4 |
| 边缘距离 `yMax` | 0.10 m |
| 支座类型 | 简支梁 |
| 支座位置 | `xA = 0 m`, `xB = 6 m` |
| 载荷 | 跨中集中力 `P = -10000 N`, `x = 3 m` |

该问题为标准简支梁跨中集中力问题。由对称性可知：

```text
RA = RB = 5000 N
```

最大剪力绝对值为：

```text
|V|max = 5000 N
```

跨中弯矩最大：

```text
|M|max = PL / 4 = 10000 * 6 / 4 = 15000 N*m
```

最大弯曲正应力为：

```text
sigma_max = |M|max yMax / I
          = 15000 * 0.10 / 8.0e-6
          = 1.875e8 Pa
          = 187.5 MPa
```

跨中最大挠度理论值为：

```text
|w|max = PL^3 / (48EI)
       = 10000 * 6^3 / (48 * 210e9 * 8.0e-6)
       = 2.6786e-2 m
       = 26.79 mm
```

程序输出的剪力、弯矩、应力和挠度曲线应与以上理论结果一致。由于程序采用离散点数值积分，最大值位置和挠度值可能存在很小的离散误差。

## 7. 典型算例验证

### 7.1 算例一：简支梁跨中集中力

该算例与主程序相同，用于验证简支梁反力、剪力、弯矩和跨中挠度计算。

| 项目 | 结果 |
| --- | --- |
| `RA` | 5000 N |
| `RB` | 5000 N |
| 最大剪力绝对值 | 5000 N |
| 最大弯矩绝对值 | 15000 N*m |
| 最大正应力 | 187.5 MPa |
| 最大挠度绝对值 | 26.79 mm |

结果说明：剪力图在跨中集中力处发生突变，弯矩图为两段直线，跨中弯矩最大；挠度曲线关于跨中对称，跨中挠度最大。

### 7.2 算例二：悬臂梁自由端集中力

算例参数如下：

| 参数 | 数值 |
| --- | --- |
| 梁长 `L` | 2.0 m |
| 弹性模量 `E` | 210 GPa |
| 截面惯性矩 `I` | 8.0e-6 m^4 |
| 边缘距离 `yMax` | 0.10 m |
| 支座类型 | 左端固定悬臂梁 |
| 载荷 | 自由端集中力 `P = -2000 N` |

计算结果为：

| 项目 | 结果 |
| --- | --- |
| 固定端竖向反力 `RA` | 2000 N |
| 固定端弯矩 `MA` | -4000 N*m |
| 最大剪力绝对值 | 2000 N |
| 最大弯矩绝对值 | 4000 N*m |
| 最大正应力 | 50.0 MPa |
| 自由端最大挠度绝对值 | 3.175 mm |

其中自由端挠度按理论公式计算为：

```text
|w|max = PL^3 / (3EI)
       = 2000 * 2^3 / (3 * 210e9 * 8.0e-6)
       = 3.175e-3 m
```

结果说明：悬臂梁最大弯矩和最大应力均出现在固定端，自由端弯矩为零，自由端挠度最大，符合材料力学理论。

### 7.3 算例三：简支梁局部均布载荷

算例参数如下：

| 参数 | 数值 |
| --- | --- |
| 梁长 `L` | 8.0 m |
| 弹性模量 `E` | 210 GPa |
| 截面惯性矩 `I` | 8.0e-6 m^4 |
| 边缘距离 `yMax` | 0.10 m |
| 支座类型 | 简支梁 |
| 均布载荷 | `q = -3000 N/m`，作用区间 `x = 2 m` 到 `x = 6 m` |

均布载荷等效合力为：

```text
F = q(6 - 2) = -12000 N
```

由于载荷关于跨中对称，支座反力为：

```text
RA = RB = 6000 N
```

跨中剪力为零，跨中弯矩最大：

```text
Mmax = 6000 * 4 - 3000 * (4 - 2)^2 / 2
     = 18000 N*m
```

最大正应力为：

```text
sigma_max = 18000 * 0.10 / 8.0e-6
          = 2.25e8 Pa
          = 225 MPa
```

按分段弯矩函数积分并利用简支梁边界条件，可得到跨中最大挠度约为：

```text
|w|max = 6.7857e-2 m = 67.86 mm
```

结果说明：该算例验证了程序对局部均布载荷的处理能力。剪力图在均布载荷区间内呈线性变化，弯矩图在载荷区间内呈二次曲线变化，最大弯矩和最大挠度均位于跨中。

## 8. 结果讨论

从上述算例可以看出，程序计算结果与材料力学经典公式一致，说明程序中支座反力、剪力弯矩、应力和挠度计算流程是正确的。

程序的主要优点是：

1. 通过结构体统一描述梁、支座和载荷，输入形式较清晰。
2. 将载荷统一转化为对剪力和弯矩的叠加贡献，减少了手工分段推导。
3. 同一套计算流程可以处理多种载荷组合。
4. 结果可视化直观，有助于理解剪力图、弯矩图和挠度曲线之间的关系。

程序也存在一些不足：

1. 当前挠度采用数值积分，结果精度受离散点数 `n` 影响。
2. 当前悬臂梁版本主要支持左端固定形式，其他固定位置还可继续扩展。
3. 程序主要考虑静定梁，对连续梁等超静定结构尚未实现。
4. 当前只计算弯曲正应力，尚未进一步计算剪应力和强度校核安全系数。

## 9. 心得体会

通过本次大作业，我将材料力学中梁弯曲问题的理论公式转化为 Matlab 程序实现。编程过程中最关键的是统一符号约定和载荷处理方式。如果符号约定不统一，支座反力、弯矩图和挠度方向很容易出现矛盾。通过将集中力、力偶和分布载荷分别写成对剪力和弯矩的贡献，可以使程序逻辑更加清楚。

另外，挠度计算体现了理论推导和数值方法之间的联系。弯矩函数经过两次积分得到转角和挠度，但积分常数必须由边界条件确定。程序中利用支座处挠度为零或固定端转角、挠度为零来修正积分结果，这与手算挠曲线方程的思路是一致的。

本次作业不仅加深了我对支座反力、剪力图、弯矩图、弯曲正应力和挠度曲线的理解，也提高了使用 Matlab 解决工程计算问题的能力。
