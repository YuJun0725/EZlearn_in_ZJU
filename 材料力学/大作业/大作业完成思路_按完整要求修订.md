# 材料力学大作业完成思路（按完整作业要求修订）

## 1. 作业要求重新梳理

根据 `作业要求` 文件夹中的 4 张要求图，本次大作业的核心要求不是必须完成某一个固定题目，而是围绕材料力学课程内容，自选一个专题，用 Matlab 完成计算、分析和展示。

必须提交的内容包括：

1. 一份计算说明书。
2. Matlab 源程序，即 `.m` 文件。
3. 具体算例、计算结果、讨论和体会。

第一页给出的总要求是：用 Matlab 编写一个材料力学相关计算程序，解决材料力学课程中涉及的某些问题。后面三页给出的是参考方向，例如：

1. 简支梁受均布载荷作用下主应力迹线的确定和绘制，也可以换成其他梁型或其他载荷形式。
2. 三跨或多跨连续梁支座反力、剪力图、弯矩图和挠曲线的计算。
3. 平面或空间应力状态的主应力大小和方向分析，可加入动画演示。
4. 两种或三种材料组合截面梁的弯曲正应力或弯曲切应力分析，并将结果图形化。
5. 组合变形结构的强度分析或设计，并讨论结构尺寸、载荷作用点等参数变化对结果的影响。
6. 从实际工程结构得到启发，对需要加强或特殊处理的位置进行进一步研究和讨论。

因此，后 3 张图并不是要求每一项都完成，而是在提示作业应尽量体现“专题研究”的深度。程序最好不只是机械套公式，还要有一个明确的材料力学问题、计算流程、结果图形和讨论。

最终程序可以分成两个层次：

### 4.1 基础层：静定梁弯曲分析

保留并完善现有功能：

1. 输入梁长、弹性模量、截面惯性矩、截面边缘距离等参数。
2. 输入支座类型：简支梁、悬臂梁、外伸梁。
3. 输入载荷类型：集中力、集中力偶、均布载荷、线性分布载荷。
4. 自动计算支座反力。
5. 计算并绘制剪力图、弯矩图、挠度曲线。
6. 计算最大弯曲正应力、最大挠度及其位置。

### 4.2 拓展层：组合材料截面弯曲应力分析

新增一个组合截面模块，分析由两种或三种材料组成的矩形组合截面梁。例如截面宽度为 `b`，高度分为 `h1`、`h2`、`h3` 三层，每层材料弹性模量分别为 `E1`、`E2`、`E3`。

程序需要完成：

1. 根据不同材料弹性模量计算等效截面。
2. 求组合截面的等效中性轴位置。
3. 求等效截面惯性矩。
4. 根据梁弯矩 `M(x)` 计算各材料层中的弯曲正应力。
5. 绘制危险截面上的正应力分布图。
6. 比较不同材料组合、不同层高、不同载荷位置对最大应力的影响。

这样既保留了现有程序工作量，又能体现后续要求中强调的“结果图形化”“参数讨论”“工程启发”。

## 5. 理论计算思路

### 5.1 静定梁内力计算

对简支梁、悬臂梁和外伸梁，先由整体平衡方程求支座反力：

```text
sum(Fy) = 0
sum(M) = 0
```

然后沿梁长方向离散为若干点，对每个截面采用截面法叠加左侧外力贡献，得到：

```text
V(x) = 截面左侧所有竖向力之和
M(x) = 截面左侧所有外力对该截面的力矩之和
```

不同载荷对剪力图和弯矩图的影响如下：

1. 集中力使剪力图发生突变，使弯矩图斜率发生变化。
2. 集中力偶使弯矩图发生突变，不改变剪力图。
3. 均布载荷使剪力图呈线性变化，使弯矩图呈二次曲线变化。
4. 线性分布载荷使剪力图呈二次曲线变化，使弯矩图呈三次曲线变化。

### 5.2 挠度曲线计算

梁弯曲挠曲线近似微分方程为：

```text
E I w''(x) = M(x)
```

程序中可以采用数值积分：

```text
theta(x) = integral(M(x) / (E I)) dx
w(x) = integral(theta(x)) dx
```

再根据边界条件修正积分常数：

1. 简支梁：两个支座处挠度为 0。
2. 悬臂梁：固定端挠度和转角均为 0。
3. 外伸梁：两个支座处挠度为 0。

### 5.3 单一材料截面弯曲正应力

单一材料梁的弯曲正应力为：

```text
sigma = M y / I
```

梁上最大弯曲正应力可写为：

```text
sigma_max = max(abs(M(x))) * y_max / I
```

当前程序已经完成这一部分。

### 5.4 组合材料截面弯曲正应力

对于组合材料截面，各材料层弹性模量不同，不能直接使用普通单一材料公式。可以采用等效截面法。

选取某一种材料作为基准材料，弹性模量为 `E0`。第 `i` 层材料的弹性模量为 `Ei`，面积为 `Ai`，形心坐标为 `yi`，则弹性模量比为：

```text
ni = Ei / E0
```

等效面积为：

```text
Ai' = ni * Ai
```

组合截面等效中性轴为：

```text
y_bar = sum(Ai' * yi) / sum(Ai')
```

等效惯性矩为：

```text
I_eq = sum(ni * (Ii_centroid + Ai * (yi - y_bar)^2))
```

其中 `Ii_centroid` 是第 `i` 层材料自身形心轴惯性矩。

第 `i` 层中距离中性轴为 `y` 的位置，其实际弯曲正应力可表示为：

```text
sigma_i = Ei / E0 * M * y / I_eq
```

由于不同材料弹性模量不同，即使应变沿截面高度线性分布，不同材料中的应力分布斜率也不同。因此在材料交界面处，应力可能出现跳变。这一点适合在说明书中重点讨论。

### 6.3 主程序调用流程

最终主流程可以写成：

```text
1. 输入梁参数、支座条件、载荷条件
2. 调用 calcReaction 计算支座反力
3. 调用 calcInternalForce 计算 V(x)、M(x)
4. 调用 calcDeflection 计算挠度曲线

8. 绘制载荷图、剪力图、弯矩图、挠度图、组合截面应力分布图
9. 进行参数变化讨论
```

## 7. 算例设计建议

### 7.1 算例一：基础验证算例

采用简支梁跨中集中力：

```text
L = 6 m
P = 10 kN
E = 210 GPa
I = 8.0e-6 m^4
```

理论结果：

```text
RA = RB = P / 2
Mmax = P L / 4
wmax = P L^3 / (48 E I)
```

这个算例用于验证程序基础计算是否正确。

### 7.2 算例二：复杂载荷算例

采用简支梁同时承受集中力、集中力偶和局部均布载荷：

```text
L = 8 m
F1 = 6 kN, x = 2 m
M0 = 4 kN*m, x = 4 m
q = 2 kN/m, x = 5 m 到 x = 8 m
```

输出：

1. 支座反力。
2. 剪力图。
3. 弯矩图。
4. 挠度曲线。
5. 最大弯矩、最大应力和最大挠度位置。

这个算例用于体现程序可处理多种载荷叠加。

### 7.3 算例三：组合材料截面梁

采用简支梁承受两个集中力，截面由三层材料组成：

```text
梁长 L = 6 m
载荷 F1 = 8 kN, x = 2 m
载荷 F2 = 5 kN, x = 4 m
截面宽度 b = 0.08 m
下层材料高度 h1 = 0.03 m, E1 = 70 GPa
中层材料高度 h2 = 0.04 m, E2 = 120 GPa
上层材料高度 h3 = 0.05 m, E3 = 200 GPa
```

需要输出：

1. 组合截面等效中性轴位置。
2. 等效截面惯性矩。
3. 危险截面位置。
4. 各材料层最大拉应力和最大压应力。
5. 危险截面的应力分布图。

这个算例直接对应第 3 页第 4 个参考方向。

### 7.4 参数变化讨论

为了体现“专题研究”深度，建议选择一个参数做变化分析，例如：

1. 改变上层高弹性模量材料的厚度 `h3`。
2. 改变载荷 `F1` 的作用位置。
3. 改变材料弹性模量比 `E3 / E1`。

观察并讨论：

1. 中性轴位置如何移动。
2. 最大拉应力和最大压应力如何变化。
3. 哪一层材料最容易成为危险层。
4. 是否可以通过调整材料布置降低最大应力。

这一部分能呼应第 4 页“结构尺寸变化、载荷作用点变化对结果的影响”的要求。
