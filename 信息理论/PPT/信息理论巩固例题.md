## 答案与解析

### 1. 答案

1. `p_X(0)=0.5,p_X(1)=0.5`；`p_Y(0)=0.4,p_Y(1)=0.6`。
2. `p(X=0|Y=0)=0.3/0.4=0.75`。
3. `I(X=0)=-log 0.5=1`；`I(X=0|Y=0)=-log 0.75≈0.415`。
4. `I(0;0)=log[0.3/(0.5*0.4)]=log 1.5≈0.585`；`I(0;1)=log[0.2/(0.5*0.6)]=log(2/3)≈-0.585`。前者为正，说明 `Y=0` 使 `X=0` 更可能；后者为负，说明 `Y=1` 使 `X=0` 更不可能。

### 2. 答案

`H(X)=1`，`H(Y)=H(0.4,0.6)≈0.971`。

```math
H(X,Y)=-(0.3log0.3+0.2log0.2+0.1log0.1+0.4log0.4)\approx 1.846
```

```math
H(X|Y)=H(X,Y)-H(Y)\approx 1.846-0.971=0.875
```

```math
I(X;Y)=H(X)-H(X|Y)\approx 1-0.875=0.125
```

也有：

```math
I(X;Y)=H(X)+H(Y)-H(X,Y)\approx 1+0.971-1.846=0.125
```

### 3. 答案

`H_2(0.1)=H_2(0.9)≈0.469`，`H_2(0.5)=1`。二元熵关于 `p=0.5` 对称，因为交换两个符号只会把 `p` 和 `1-p` 互换。最大值在均匀分布 `p=0.5` 处取得。

### 4. 答案

细分类熵：

```math
H(X)=-(0.1log0.1+0.2log0.2+0.3log0.3+0.4log0.4)\approx 1.846
```

粗分组概率为 `P(A)=0.3,P(B)=0.7`，所以：

```math
H(G)=H(0.3,0.7)\approx 0.881
```

组内条件熵：

```math
H(X|G)=0.3H(1/3,2/3)+0.7H(3/7,4/7)\approx 0.965
```

因此 `H(G)+H(X|G)≈0.881+0.965=1.846=H(X)`。

### 5. 答案

```math
H(X)=-(0.5log0.5+0.3log0.3+0.2log0.2)\approx 1.485
```

```math
H_2^{Renyi}(X)=-log(0.5^2+0.3^2+0.2^2)=-log0.38\approx 1.396
```

二阶 Rényi 熵比 Shannon 熵小。因为平方会放大大概率项在求和中的影响，使分布看起来更“集中”。

### 6. 答案

```math
D(p||q)=0.5log\frac{0.5}{0.4}+0.3log\frac{0.3}{0.4}+0.2log\frac{0.2}{0.2}\approx 0.0365
```

```math
D(q||p)=0.4log\frac{0.4}{0.5}+0.4log\frac{0.4}{0.3}+0.2log\frac{0.2}{0.2}\approx 0.0372
```

二者不相等，所以 KL 散度不满足距离的对称性要求。

### 7. 答案

经验分布为 `p_emp=(0.5,0.3,0.2)`。样本平均对数似然为：

```math
\ell(\theta)=0.5log\theta+0.3log\frac{1-\theta}{2}+0.2log\frac{1-\theta}{2}
=0.5log\theta+0.5log\frac{1-\theta}{2}
```

忽略常数 `-0.5log2`，最大化 `0.5log theta+0.5log(1-theta)`，得到：

```math
\hat\theta=0.5
```

因为：

```math
D(p_{emp}||q_\theta)=\sum_x p_{emp}(x)\log p_{emp}(x)-\sum_x p_{emp}(x)\log q_\theta(x)
```

第一项与 `theta` 无关，所以最小化 KL 等价于最大化经验平均对数似然。

### 8. 答案

Fano 不等式给出：

```math
H(X|X_hat)\le H_2(0.1)+0.1log(4-1)
```

其中 `H_2(0.1)≈0.469`，`0.1log3≈0.1585`，所以上界约为：

```math
0.6275 bit
```

若声称 `H(X|X_hat)=1.2 bit` 且 `P_E=0.1`，则违反上界，不可能成立。

### 9. 答案

1. 由链式关系：

```math
I(X;Y,Z)=I(X;Y)+I(X;Z|Y)=0.3+0.5=0.8
```

2. 不可能。若 `X -> Y -> Z`，数据处理定理给出 `I(X;Z)<=I(X;Y)`。
3. 不可能。若 `U -> X -> Y -> V`，则 `I(U;V)<=I(X;Y)=0.8`。

### 10. 答案

均匀分布微分熵：

