说明：默认 `log` 以 2 为底，单位为 bit；若使用自然对数，则单位为 nat。连续随机变量的微分熵在课件中也常写作 `H_C(X)` 或 `h(X)`。

## 0. 总体框架

信息理论主线可以压缩成三句话：

1. 信息的度量：用自信息、熵、互信息、相对熵等量刻画“不确定性”和“相关性”。
2. 信息的压缩：信源熵给出无损压缩的极限，编码算法试图逼近这个极限。
3. 信息的传输：信道容量给出可靠通信的极限，编码定理说明低于容量的速率可可靠传输。

对应关系：

| 问题 | 核心量 | 极限定理 |
|---|---:|---|
| 一条消息有多少信息？ | 自信息 `I(x)=-log p(x)` | 越罕见的信息量越大 |
| 一个信源平均有多少信息？ | 熵 `H(X)` | 无损压缩平均码率不能低于熵 |
| 两个随机变量共享多少信息？ | 互信息 `I(X;Y)` | 信道容量是互信息最大值 |
| 两个分布相差多少？ | KL 散度 `D(p||q)` | 非负，常用于估计和逆定理 |
| 信道最多能传多少？ | 容量 `C` | `R<C` 可可靠传输，`R>C` 不可达 |

## 1. 信息的度量

### 1.1 随机变量、联合分布与条件分布

离散随机变量可写为 `{X, X, q(x)}`：

- `X={x_k; k=1,2,...,K}` 是取值集合。
- `q(x)=P{X=x}`，满足 `q(x)>=0` 且 `sum_x q(x)=1`。

二维随机变量 `{(X,Y), X×Y, p(x,y)}`：

- `p(x_k,y_j)=P{X=x_k,Y=y_j}`。
- 边缘分布：

```math
q(x_k)=\sum_j p(x_k,y_j),\qquad \omega(y_j)=\sum_k p(x_k,y_j)
```

- 条件分布：

```math
p(y_j|x_k)=\frac{p(x_k,y_j)}{q(x_k)},\qquad
p(x_k|y_j)=\frac{p(x_k,y_j)}{\omega(y_j)}
```

### 1.2 自信息、条件自信息、互信息

#### 自信息

事件 `{X=x_k}` 的自信息：

```math
I(x_k)=-\log_a q(x_k)
```

性质：

- `q(x_k)` 越小，`I(x_k)` 越大。
- 必然事件 `q(x_k)=1` 的自信息为 0。
- 若 `q(x_k)->0`，则 `I(x_k)->infty`。
- 独立事件联合发生时，自信息相加。

例：若 `p(x)=1/8`，则 `I(x)=3 bit`。

#### 条件自信息

已知 `{Y=y_j}` 时 `{X=x_k}` 的条件自信息：

```math
I(x_k|y_j)=-\log p(x_k|y_j)
```

一个观测 `y_j` 可能让事件 `x_k` 更确定，也可能让它更不确定：

- 若 `p(x_k|y_j)>p(x_k)`，则 `I(x_k|y_j)<I(x_k)`。
- 若 `p(x_k|y_j)<p(x_k)`，则 `I(x_k|y_j)>I(x_k)`。
- 若两者独立，则 `I(x_k|y_j)=I(x_k)`。

#### 事件互信息

两个事件相互提供的信息：

```math
I(x_k;y_j)=I(x_k)-I(x_k|y_j)
          =\log\frac{p(x_k|y_j)}{q(x_k)}
          =\log\frac{p(x_k,y_j)}{q(x_k)\omega(y_j)}
```

事件互信息可以为正、负或零：

- 正：`y_j` 使 `x_k` 更可能。
- 负：`y_j` 使 `x_k` 更不可能。
- 零：`x_k` 与 `y_j` 独立。

#### 联合自信息、条件互信息和链式关系

联合自信息：

```math
I(x_k,y_j)=-\log p(x_k,y_j)
```

条件互信息：

```math
I(x;y|z)=\log\frac{p(x|y,z)}{p(x|z)}
        =\log\frac{p(x,y|z)}{p(x|z)p(y|z)}
```

联合互信息：

```math
I(x;y,z)=I(x;y)+I(x;z|y)
```

这条链式关系非常重要：新增一个观测 `z` 对 `x` 的增量贡献，要在已知 `y` 的条件下计算。

### 1.3 熵、联合熵、条件熵

#### 熵

随机变量的熵是平均自信息：

```math
H(X)=E[I(X)]=-\sum_{x\in X} q(x)\log q(x)
```

二元变量 `P(X=x_1)=p, P(X=x_2)=1-p`：

```math
H(X)=-p\log p-(1-p)\log(1-p)
```

结论：

- `p=0` 或 `p=1` 时，`H(X)=0`，因为没有不确定性。
- `p=0.5` 时，`H(X)=1 bit`，二元变量不确定性最大。
- 均匀分布时熵最大：`H(X)<=log K`。

#### 联合熵

```math
H(X,Y)=-\sum_x\sum_y p(x,y)\log p(x,y)
```

含义：描述二元随机变量整体的不确定性。

#### 条件熵

给定 `Y=y` 时：

```math
H(X|y)=-\sum_x p(x|y)\log p(x|y)
```

平均条件熵：

```math
H(X|Y)=-\sum_x\sum_y p(x,y)\log p(x|y)
```

注意：

- 对某个具体条件 `y`，可能出现 `H(X|y)>H(X)`。
- 但平均后有 `H(X|Y)<=H(X)`，即平均意义下“条件不会增加不确定性”。
- 若 `X` 与 `Y` 独立，则 `H(X|Y)=H(X)`。

#### 熵的链式法则

```math
H(X,Y)=H(X)+H(Y|X)=H(Y)+H(X|Y)
```

推广到多个变量：

```math
H(X,Y,Z)=H(X)+H(Y|X)+H(Z|X,Y)
```

### 1.4 熵的主要性质

设 `P=(p_1,...,p_K)`：

```math
H_K(P)=-\sum_{k=1}^K p_k\log p_k
```

课件中的核心性质：

- 对称性：熵只与概率集合有关，与符号名称无关。
- 非负性：`H(X)>=0`。
- 确定性：若某个概率为 1，其余为 0，则 `H(X)=0`。
- 连续性：概率中加入趋近 0 的事件不会突变改变熵。
- 扩展/分组性质：先粗分组再描述组内细节，总熵等于粗分组熵加组内条件熵。
- 极大性：`H(X)<=log K`，等号在均匀分布时成立。
- 条件降低熵：`H(X|Y)<=H(X)`。
- 凹性：`H(theta P_1+(1-theta)P_2) >= theta H(P_1)+(1-theta)H(P_2)`。

分组性质可理解为：

```math
H(\text{细分类}) = H(\text{粗分类}) + H(\text{细分类}|\text{粗分类})
```

例：先判断“字母/数字”，再判断具体字符，总信息量等于两步平均信息量之和。

### 1.5 Rényi 熵

课件还给出 Rényi 熵：

```math
H_\alpha(X)=\frac{1}{1-\alpha}\log\sum_x p(x)^\alpha
```

当 `alpha -> 1` 时，Rényi 熵收敛到 Shannon 熵。它通过参数 `alpha` 调节对大概率或小概率事件的敏感程度。

### 1.6 随机变量间的平均互信息

平均互信息：

```math
I(X;Y)=E[I(x;y)]
      =\sum_x\sum_y p(x,y)\log\frac{p(x|y)}{p(x)}
      =\sum_x\sum_y p(x,y)\log\frac{p(x,y)}{p(x)p(y)}
```

等价形式：

```math
I(X;Y)=H(X)-H(X|Y)
      =H(Y)-H(Y|X)
      =H(X)+H(Y)-H(X,Y)
```

性质：

- 非负性：`I(X;Y)>=0`。
- 对称性：`I(X;Y)=I(Y;X)`。
- 上界：`I(X;Y)<=H(X)` 且 `I(X;Y)<=H(Y)`。
- 独立当且仅当 `I(X;Y)=0`。

例：一个二元变量 `X` 和观测 `Y`。

- 若 `P(X=0)=0.98`，即原本已经很确定，观测能降低的不确定性有限，课件例子得到 `I(X;Y)=0.0178 bit`。
- 若 `P(X=0)=P(X=1)=0.5`，原本最不确定，同样类型观测能提供更多信息，课件例子得到 `I(X;Y)=0.3115 bit`。

理解：互信息衡量“观测前后熵减少了多少”，所以初始不确定性越大，观测可能带来的信息越多。

### 1.7 KL 散度与最大似然

KL 散度，又称相对熵：

```math
D(p||q)=\sum_x p(x)\log\frac{p(x)}{q(x)}
       =E_p\left[\log\frac{p(X)}{q(X)}\right]
```

性质：

- `D(p||q)>=0`，等号当且仅当 `p=q`。
- 一般 `D(p||q) != D(q||p)`，因此它不是距离。
- 若 `U` 是均匀分布，则：

```math
H(X)=\log K-D(p_X||U)
```

所以均匀分布让熵最大。

- 对独立乘积分布：

```math
D(P_1P_2||Q_1Q_2)=D(P_1||Q_1)+D(P_2||Q_2)
```

与最大似然的关系：若真实分布为 `p(x)`，模型分布为 `q(x|theta)`，最小化

```math
D(p||q_\theta)
```

等价于最大化样本平均对数似然，因为其中与 `theta` 无关的 `log p(x)` 可忽略。

### 1.8 Fano 不等式

设 `X` 在 `K` 个符号上取值，`X_hat` 是对 `X` 的估计，错误概率：

```math
P_E=P\{X\ne \hat X\}
```

Fano 不等式：

```math
H(X|\hat X)\le H(P_E)+P_E\log(K-1)
```

含义：

- 若估计错误率很小，则估计后的剩余不确定性也小。
- 若剩余条件熵很大，则不可能有很小错误率。
- 该不等式在信道编码逆定理中用于证明 `R>C` 不可可靠传输。

### 1.9 马尔可夫链与数据处理定理

若

```math
p(x,y,z)=p(x)p(y|x)p(z|y)
```

则记作：

```math
X -> Y -> Z
```

等价地：

```math
p(z|x,y)=p(z|y),\qquad I(X;Z|Y)=0
```

数据处理定理：

```math
X -> Y -> Z \quad \Rightarrow \quad I(X;Y)\ge I(X;Z)
```

更一般地：

```math
U -> X -> Y -> V \quad \Rightarrow \quad I(U;V)\le I(X;Y)
```

含义：对数据做处理不能凭空增加关于原始变量的信息。压缩、量化、信道传输、分类器后处理都受这一定理约束。

互信息的凸性/凹性：

- 固定信道 `p(y|x)` 时，`I(X;Y)` 是输入分布 `p(x)` 的凹函数。
- 固定输入分布 `p(x)` 时，`I(X;Y)` 是信道转移概率 `p(y|x)` 的凸函数。

这为信道容量优化提供理论基础。

## 2. 连续随机变量、微分熵与平稳信源

### 2.1 连续随机变量的密度与互信息

连续二维随机变量用联合密度 `p_{XY}(x,y)` 描述：

```math
p_X(x)=\int_{-\infty}^{+\infty} p_{XY}(x,y)\,dy,\qquad
p_{Y|X}(y|x)=\frac{p_{XY}(x,y)}{p_X(x)}
```

连续互信息由离散互信息取极限得到：

```math
I(X;Y)=\iint p_{XY}(x,y)\log
\frac{p_{XY}(x,y)}{p_X(x)p_Y(y)}\,dxdy
```

条件互信息：

```math
I(X;Y|Z)=\iiint p_{XYZ}(x,y,z)\log
\frac{p_{XY|Z}(x,y|z)}{p_{X|Z}(x|z)p_{Y|Z}(y|z)}\,dxdydz
```

连续互信息仍满足：

- `I(X;Y)>=0`
- `I(X;Y)=I(Y;X)`
- `I(X;YZ)=I(X;Y)+I(X;Z|Y)`
- 若 `X->Y->Z`，则 `I(X;Y)>=I(X;Z)`。

### 2.2 微分熵

连续随机变量的微分熵：

```math
h(X)=H_C(X)=-\int p_X(x)\log p_X(x)\,dx
```

注意：

- 微分熵不是离散熵的直接连续版本。离散化时会多出 `-log Delta` 项。
- 微分熵可以为负。
- 微分熵不具有一般坐标变换不变性；若 `Y=aX`，则 `h(Y)=h(X)+log|a|`。
- 互信息是坐标变换下更稳定的量。

均匀分布例子：若 `X~Unif[a,b]`，

```math
h(X)=\log(b-a)
```

量化例子：若位置在 `[0,L]` 上均匀，测量精度为 `Delta`，则可分辨的信息量近似为：

```math
I(X;Y)=\log\frac{L}{\Delta}
```

### 2.3 连续联合熵、条件熵与互信息

```math
h(X,Y)=-\iint p_{XY}(x,y)\log p_{XY}(x,y)\,dxdy
```

```math
h(X|Y)=-\iint p_{XY}(x,y)\log p_{X|Y}(x|y)\,dxdy
```

链式法则仍成立：

```math
h(X,Y)=h(X)+h(Y|X)=h(Y)+h(X|Y)
```

互信息：

```math
I(X;Y)=h(X)-h(X|Y)
      =h(Y)-h(Y|X)
      =h(X)+h(Y)-h(X,Y)
```

### 2.4 高斯变量、最大微分熵与熵功率

二维联合高斯变量的互信息只与相关系数 `rho` 有关：

```math
I(X;Y)=-\frac{1}{2}\log(1-\rho^2)
```

当 `rho=0` 时互信息为 0；当 `|rho|` 趋近 1 时，互信息趋大。

微分熵极值：

- 若 `X` 支持在 `(-M,M)`，则

```math
h(X)\le \ln(2M)
```

等号在均匀分布时成立。

- 若 `X` 方差为 `sigma^2`，则

```math
h(X)\le \frac{1}{2}\ln(2\pi e\sigma^2)=\ln(\sqrt{2\pi e}\sigma)
```

等号在高斯分布时成立。

熵功率：

```math
N(X)=\frac{1}{2\pi e}e^{2h(X)}
```

高斯变量满足 `N(X)=sigma^2`。熵功率把“熵”转换成等效高斯方差，常用于高斯信道容量证明。

## 3. 平稳离散信源与马尔可夫信源的熵

### 3.1 平稳随机过程与平稳信源

平稳随机过程：任意有限维分布对时间平移不变，即对任意 `h`，

```math
(X(t_1),...,X(t_n))
```

与

```math
(X(t_1+h),...,X(t_n+h))
```

同分布。

离散平稳信源：

```math
Pr(X_1X_2...X_L)=Pr(X_{1+n}X_{2+n}...X_{L+n})
```

无记忆信源：

```math
Pr(X_1...X_L)=\prod_{i=1}^L Pr(X_i)
```

`m` 阶马尔可夫信源：

```math
Pr(X_l|X_{l-1}...X_0)=Pr(X_l|X_{l-1}...X_{l-m})
```

### 3.2 块熵与熵率

长度 `N` 的块熵：

```math
H(X_1^N)=H(X_1,X_2,...,X_N)
```

平均块熵：

```math
H_N(X)=\frac{1}{N}H(X_1,X_2,...,X_N)
```

熵率：

```math
H_\infty(X)=\lim_{N\to\infty}H_N(X)
```

对于平稳信源：

```math
H_\infty(X)=\lim_{N\to\infty}H(X_N|X_{N-1},...,X_1)
```

性质：

- `H(X_N|X_{N-1},...,X_1)` 随 `N` 非增。
- `H_N(X)` 随 `N` 非增。
- `H_N(X)>=H(X_N|X_{N-1},...,X_1)`。
- `H_\infty(X)<=log K`。

冗余度：

```math
\eta=\frac{H_\infty(X)}{\log K},\qquad R=1-\eta
```

自然语言例子：字母独立等概时熵高；考虑字母频率、相邻字母、词法语法后，熵率显著下降，说明自然语言有大量冗余。

### 3.3 马尔可夫信源熵率

对 `m` 阶马尔可夫信源，可把长度为 `m` 的历史视为状态：

```math
S_n=(X_{n-1},X_{n-2},...,X_{n-m})
```

状态转移矩阵：

```math
P=[p_{ij}]
```

平稳状态分布满足：

```math
\bar Q=\bar Q P
```

熵率：

```math
H_\infty=H(X|S)=\sum_s q(s)H(X|S=s)
```

二状态马尔可夫链：

```math
P=\begin{bmatrix}
1-\alpha & \alpha\\
\beta & 1-\beta
\end{bmatrix}
```

平稳分布：

```math
\mu_1=\frac{\beta}{\alpha+\beta},\qquad
\mu_2=\frac{\alpha}{\alpha+\beta}
```

熵率：

```math
H_\infty=\mu_1H(\alpha,1-\alpha)+\mu_2H(\beta,1-\beta)
```

课件二阶马尔可夫示例以 `00,01,10,11` 为 4 个状态，得到：

```math
H_\infty\approx 0.802 bit
```

## 4. 信源编码与无损压缩

### 4.1 信源编码目标

信源是产生消息或消息序列的源，例如图像、语音、符号、DNA 序列。

信息论中的信源问题：

1. 用随机变量序列或随机过程描述信源。
2. 计算信源输出的信息量，即信源熵。
3. 设计有效表示信源输出的方法，即信源编码。

信源编码目标：用最少代价表示信源。课件中把编码分为：

- 无损编码：
  - 绝对无差错编码：`P_e^{(n)}=0, forall n`
  - 渐进无差错编码：`P_e^{(n)} -> 0`
- 有损编码：限失真编码。

### 4.2 离散无记忆信源 DMS 与等长编码

DMS：

- 字符表 `A={a_1,...,a_K}`
- 概率分布 `{p_1,...,p_K}`
- 长度为 `L` 的信源序列共有 `K^L` 个。

编码字符表 `B={b_1,...,b_D}`，码字长度为 `N`。若要对所有长度 `L` 的序列无损等长编码：

```math
D^N\ge K^L
```

即：

```math
N\ge \frac{L\log K}{\log D}
```

例：十进制数字用二进制等长表示。

- 单个数字：`N>=log 10`，需要 4 bit。
- 两个数字联合编码：`N>=log 100`，需要 7 bit，平均 3.5 bit/数字。
- 序列越长，平均长度越接近 `log 10=3.322 bit/数字`，但译码时延也越大。

### 4.3 Shannon 信源编码定理与 AEP

对 DMS，等长编码的极限由熵决定。

Shannon 信源编码定理：

- 当

```math
N>\frac{L(H(U)+\epsilon)}{\log D}
```

时，可以实现渐进无差错编码。

- 当

```math
N<\frac{L(H(U)-\epsilon)}{\log D}
```

时，不存在渐进无差错编码。

编码速率：

```math
R=\frac{N}{L}\log D \to H(U)
```

注意：这里的“无损”是错误概率可任意小，并非每个有限长度块都绝对零错误。

#### 渐进等分性质 AEP

长度 `L` 的序列 `u^L`：

```math
p(u^L)=\prod_{l=1}^L p(u_l)
```

序列自信息平均值：

```math
I_L=-\frac{1}{L}\log p(u^L)=\frac{1}{L}\sum_{l=1}^L I(u_l)
```

则：

```math
I_L \to H(U)
```

概率意义下收敛。课件用切比雪夫不等式给出：

```math
P\{|I_L-H(U)|>\epsilon\}\le \frac{\sigma_I^2}{L\epsilon^2}
```

#### 典型列

`epsilon` 典型集：

```math
A_\epsilon^{(L)}(U)=
\left\{
u^L:\left|-\frac{1}{L}\log p(u^L)-H(U)\right|<\epsilon
\right\}
```

性质：

1. `Pr{u^L in A_\epsilon^{(L)}}>1-\epsilon`，当 `L` 足够大。
2. 典型列概率近似：

```math
2^{-L(H(U)+\epsilon)}\le p(u^L)\le 2^{-L(H(U)-\epsilon)}
```

3. 典型集大小近似：

```math
(1-\epsilon)2^{L(H(U)-\epsilon)}
\le |A_\epsilon^{(L)}|
\le 2^{L(H(U)+\epsilon)}
```

直观理解：虽然总序列数是 `K^L`，但高概率质量集中在大约 `2^{LH(U)}` 个典型序列上。因此只需编码典型集即可逼近熵极限。

### 4.4 不等长编码基本概念

不等长编码用短码表示高概率符号，用长码表示低概率符号。

例：信源 `{a_1,a_2,a_3}` 概率 `{0.5,0.25,0.25}`，编码：

```text
a1 -> 1
a2 -> 00
a3 -> 01
```

平均码长：

```math
\bar n=0.5\times1+0.25\times2+0.25\times2=1.5 bit
```

等于该信源熵。

相关定义：

- 非奇异码：不同消息对应不同码字。
- 码扩展：序列编码为单符号码字的串接。
- 唯一可译码：任意扩展仍非奇异，即任意码字串只有一种分解。
- 即时可译码/前缀码/异字头码：没有任何码字是另一个码字的前缀，可边接收边译码。

唯一可译不一定即时可译；即时可译一定唯一可译。

### 4.5 Sardinas-Patterson 判据

Sardinas-Patterson 判据用于判断一个码是否唯一可译。

思想：

- 构造后缀分解集 `S_1,S_2,...`。
- 若除 `S_0` 外没有任何后缀分解集中包含原码字，则码唯一可译。
- 若 `S_1=empty`，则码是即时可译码。
- 若某个 `S_n=empty`，则码唯一可译且译码延时有限。

这部分常用于判断题：不要只看“没有重复码字”，还要检查串接后是否有歧义。

### 4.6 Kraft 不等式

存在长度为 `n_1,...,n_K` 的 `D` 元前缀码的充要条件：

```math
\sum_{k=1}^K D^{-n_k}\le 1
```

进一步：

- 任何唯一可译码也必须满足 Kraft 不等式。
- 只要一组长度满足 Kraft 不等式，就能构造同样长度的前缀码。

因此在平均码长优化中，可以把“唯一可译码”转化为更方便的“前缀码”来考虑。

### 4.7 不等长编码定理

任意唯一可译 `D` 元码平均码长 `\bar n` 满足：

```math
\bar n\ge \frac{H(U)}{\log D}
```

同时一定存在一个 `D` 元唯一可译码，使：

```math
\bar n<\frac{H(U)}{\log D}+1
```

对长度为 `L` 的平稳信源块编码：

```math
\frac{H(U^L)}{L\log D}\le \bar n
<\frac{H(U^L)}{L\log D}+\frac{1}{L}
```

当 `L->infty` 时，单位符号码率趋于熵率。

### 4.8 Huffman 编码

Huffman 编码是在平均码长最短意义下的最佳前缀码。

二元最佳码性质：

1. 概率越小，码长越长：

```math
p_1\ge p_2\ge ...\ge p_K \Rightarrow n_1\le n_2\le ...\le n_K
```

2. 概率最小的两个符号码长相等。
3. 概率最小的两个符号码字最后一位不同，且是兄弟节点。

算法：

1. 将概率从小到大排序。
2. 合并最小的两个概率，形成辅助源。
3. 对辅助源递归编码。
4. 回溯时给合并的两个分支补 `0/1`。

`D` 元 Huffman：

- 每次合并 `D` 个最小概率。
- 若 `K` 不满足 `K=(D-1)i+1`，需补 `D-M` 个概率为 0 的虚拟符号，使树完整。

### 4.9 Shannon 编码

Shannon 编码码长：

```math
l_k=\left\lceil\log\frac{1}{p_k}\right\rceil
```

令累积分布：

```math
P_k=\sum_{i=1}^{k-1}p_i
```

取 `P_k` 的二进制展开前 `l_k` 位作为码字。

性质：

- Shannon 码是前缀码。
- 平均码长满足：

```math
H(U)\le \bar l < H(U)+1
```

- 与 Huffman 相比，Shannon 编码不一定最优，尤其在概率极不均衡时可能浪费明显。

### 4.10 Fano 编码

Fano 编码步骤：

1. 将符号按概率从大到小排序。
2. 将符号分成两组，使两组概率和尽量接近。
3. 两组分别赋 `0` 和 `1`。
4. 对每组递归执行。

特点：

- 是前缀码。
- 构造直观，但一般不保证全局最优。
- 课件给出效率界：`\bar n <= H(U)+1-2p_n`，其中 `p_n` 为最小符号概率。

### 4.11 Shannon-Fano-Elias 编码

特点：不需要对概率排序。

定义：

```math
F(x)=\sum_{i<x}p(i)+\frac{1}{2}p(x)
```

码长：

```math
l(x)=\left\lceil\log\frac{1}{p(x)}\right\rceil+1
```

取 `F(x)` 的二进制展开前 `l(x)` 位作为码字。

平均码长：

```math
\bar n < H(U)+2
```

### 4.12 平稳信源与马尔可夫信源编码

对平稳有记忆信源，最优单位符号码长由熵率决定：

```math
\frac{H(U|U^\infty)}{\log D}
\le \bar n
<\frac{H(U|U^\infty)}{\log D}+\epsilon
```

马尔可夫信源：

```math
H_\infty(U)=\sum_s q(s)H(U|s)=H(U|S)
```

编码思路：

1. 先编码初始状态，约需 `ceil(log |S|)` bit。
2. 对每个状态下的输出序列分别做不等长编码。
3. 序列足够长时，初始状态开销可忽略，码率逼近 `H(U|S)`。

课件例子中：

```math
H(X|S)=0.558 bit
```

单符号二元编码至少需要 1 bit/符号；若对二符号序列按状态编码，平均码长可降到约 `0.6917 bit/符号`；继续增大块长还能进一步接近熵率。

## 5. 信道与信息传输

### 5.1 信道模型与分类

信道的数学模型：

```math
\{X; p(y|x); Y\}
```

离散无记忆信道 DMC：

```math
p(y^N|x^N)=\prod_{n=1}^N p(y_n|x_n)
```

平稳信道：

```math
p(y_n=j|x_n=k)=p(y_m=j|x_m=k),\quad \forall m,n
```

信道分类：

- 按幅度/时间取值：离散时间离散幅度、离散时间连续幅度、连续时间连续幅度、连续时间离散幅度。
- 按记忆性：有记忆信道、无记忆信道。
- 按输入输出关系：确定信道、随机信道。

### 5.2 信道容量

一般定义：

```math
C=\lim_{n\to\infty}\frac{1}{n}\max_{Q(x^n)}
I(X_1...X_n;Y_1...Y_n)
```

含义：平均每次使用信道，输入输出之间能提供的最大互信息。

对 DMC：

```math
C=\max_{p(x)} I(X;Y)
```

证明关键：

```math
I(X_1...X_N;Y_1...Y_N)\le \sum_{n=1}^N I(X_n;Y_n)
```

等号在输入独立时达到。

### 5.3 DMC 容量典型例子

#### 无噪信道

`H(X|Y)=0`，输出能确定输入：

```math
I(X;Y)=H(X),\qquad C=\max H(X)=\log M
```

#### 无损信道

同样有 `H(X|Y)=0`，因此：

```math
C=\log M
```

#### 确定信道

若 `p(y|x)` 只取 0 或 1，则 `H(Y|X)=0`：

```math
I(X;Y)=H(Y)
```

容量等于输出可达类别数的对数。

#### 无用信道

若：

```math
p(y|x)=p(y)
```

则输入输出独立：

```math
I(X;Y)=0,\qquad C=0
```

#### 复制信道

课件中复制信道满足：

```math
I(X;Y)=H(Y)-1
```

因此：

```math
C=\max H(Y)-1
```

#### 二元对称信道 BSC

交叉概率为 `p`：

```math
C=1-H_2(p)
```

其中：

```math
H_2(p)=-p\log p-(1-p)\log(1-p)
```

例：`p=0.1` 时 `H_2(0.1)≈0.469`，所以 `C≈0.531 bit/use`。

#### 二元删除/擦除信道 BEC

若擦除概率为 `epsilon`：

```math
C=1-\epsilon
```

BSC 与 BEC 的启示：擦除比错误“更可控”，因为接收端知道哪些符号不可靠。

#### K 元对称信道

```math
p(j|k)=
\begin{cases}
1-p, & j=k\\
\frac{p}{K-1}, & j\ne k
\end{cases}
```

容量：

```math
C=\log K+(1-p)\log(1-p)+p\log\frac{p}{K-1}
=\log K-H(p)-p\log(K-1)
```

#### 模 K 加法信道

```math
Y=X+Z \pmod K
```

容量：

```math
C=\log K-H(Z)
```

噪声 `Z` 均匀时容量为 0；噪声确定时容量为 `log K`。

### 5.4 信道组合

#### 平行信道/积信道

多个信道并行使用，容量相加：

```math
C=\sum_i C_i
```

#### 开关信道/和信道

每次选择使用某一个子信道。两个子信道时：

```math
C=\max_{P_A,P_B}\{P_A C_1+P_B C_2-P_A\log P_A-P_B\log P_B\}
```

常用闭式：

```math
C=\log(2^{C_1}+2^{C_2})
```

直观：开关本身也能携带“选择了哪个信道”的信息。

#### 级联信道

若 `X->Y->Z`：

```math
I(X;Y)\ge I(X;Z),\qquad I(Y;Z)\ge I(X;Z)
```

级联不会增加信息，容量受瓶颈限制。

两个 BSC 级联时，等效交叉概率：

```math
p*q=p(1-q)+(1-p)q
```

容量：

```math
C=1-H_2(p*q)
```

### 5.5 DMC 容量优化定理

定义对某个输入符号 `k` 的条件互信息期望：

```math
I(X=k;Y)=\sum_j p(j|k)\log
\frac{p(j|k)}{\sum_i Q_i p(j|i)}
```

输入分布 `{Q_k}` 达到容量 `C` 的充要条件：

```math
I(X=k;Y)=C,\quad \forall k, Q_k>0
```

```math
I(X=k;Y)<C,\quad \forall k, Q_k=0
```

含义：容量达到时，所有实际使用的“好输入符号”贡献相等；不用的输入符号贡献不超过容量。

课件中的证明使用 KKT 条件。因为固定信道时 `I(X;Y)` 对输入分布是凹函数，KKT 条件也是全局最优条件。

### 5.6 对称与准对称信道

转移矩阵 `P={p(j|k)}`。

- 输入对称：每一行都是第一行的置换。
- 输出对称：每一列都是第一列的置换。
- 对称信道：既输入对称又输出对称。
- 准对称信道：按列划分为若干子信道，每个子信道对称。

准对称 DMC 容量定理：

- 达到容量的输入分布是均匀分布。

若信道对称，则：

```math
C=\log J+\sum_j p(j|k)\log p(j|k)
```

即：

```math
C=\log J-H(\text{任意一行})
```

若只关于输入对称，则有：

```math
C\le \log J-H(\text{任意一行})
```

### 5.7 转移概率矩阵可逆信道的容量计算

容量达到时：

```math
\sum_j p(j|k)\log p(j|k)-\sum_j p(j|k)\log \omega_j=C
```

令：

```math
\beta_j=C+\log\omega_j,\qquad
\alpha_k=\sum_j p(j|k)\log p(j|k)
```

得到线性方程：

```math
P\beta=\alpha
```

若 `P` 可逆，可先解出 `beta`，再由：

```math
\omega_j=2^{\beta_j-C},\qquad \sum_j\omega_j=1
```

求容量 `C`，最后由：

```math
\omega_j=\sum_i Q_i p(j|i)
```

反求输入分布 `{Q_i}`。

若算出某个 `Q_i<0`，说明该输入符号不应使用，需要删去某些输入符号后重新计算。

## 6. 离散无记忆信道编码定理

### 6.1 信道编码定义

一个 `(M,n)` 码包含：

1. 消息集合 `W={1,2,...,M}`。
2. 编码器：把消息 `w` 映射成码字 `x^n(w)`。
3. 译码器：`g:Y^n -> W`。

发送第 `i` 个消息的错误概率：

```math
\lambda_i=P\{g(Y^n)\ne i|X^n=x^n(i)\}
```

最大错误概率：

```math
\lambda^{(n)}=\max_i\lambda_i
```

平均错误概率：

```math
P_e^{(n)}=\frac{1}{M}\sum_{i=1}^M\lambda_i
```

编码速率：

```math
R=\frac{\log M}{n}
```

若存在一系列 `(2^{nR},n)` 码，使 `lambda^{(n)}->0`，则称速率 `R` 可达。

### 6.2 香农信道编码定理

若 `R<C`，则存在一系列码使错误概率趋于 0。所有低于容量的速率均可达。

逆定理：若一系列 `(2^{nR},n)` 码满足错误概率趋于 0，则必有：

```math
R\le C
```

直观说明：

```math
M\approx \frac{2^{nH(Y)}}{2^{nH(Y|X)}}=2^{nI(X;Y)}
```

所以每次使用信道最多区分约 `2^{nC}` 个消息。

### 6.3 随机编码与联合典型译码

证明思路：

1. 随机生成码书。
2. 接收端寻找与接收序列联合典型的码字。
3. 错误事件分两类：
   - 真实码字与接收序列不联合典型。
   - 其他码字与接收序列也联合典型。
4. 联合典型性质给出：

```math
P(E_i)\le 2^{-n(I(X;Y)-3\epsilon)}
```

因此：

```math
P(E)\le \epsilon+2^{-n(I(X;Y)-R-3\epsilon)}
```

当 `R<I(X;Y)-3epsilon` 时，错误概率趋于 0。

### 6.4 信道编码逆定理

由 Fano 不等式：

```math
H(W|\hat W)\le H(P_e^{(n)})+P_e^{(n)}nR
```

再由数据处理定理：

```math
I(W;\hat W)\le I(X^n;Y^n)\le nC
```

得到：

```math
R\le P_e^{(n)}R+\frac{1}{n}+C
```

若 `R>C`，错误概率不能趋于 0。

### 6.5 理想反馈对 DMC 容量的影响

结论：

```math
C_{FB}=C
```

理想反馈不能增加 DMC 的容量。

但反馈仍有工程价值：

- 可以帮助构造更简单、性能更好的编码。
- 对有记忆信道，反馈可能提高容量。
- 非理想反馈、有限反馈是更复杂的问题。

### 6.6 信源信道分离与联合编码

分离编码：

```math
H(W)<R_s<R_c<C \Rightarrow P_e^{(n)}\to 0
```

联合编码定理：

- 若有限字母信源熵率 `H(V)<C`，则可可靠传输。
- 若 `H(V)>C`，则不可能以任意小错误概率传输。

结论：

- 分离编码不降低可达极限，工程实现更简单。
- 联合编码不能提高理论可行速率上限，但可能降低复杂度或改善有限长度性能。

## 7. 加性高斯噪声信道 AWGN

### 7.1 时间离散 AWGN 信道

```math
Y_i=X_i+Z_i
```

功率约束：

```math
\frac{1}{n}\sum_{i=1}^n x_i^2\le P
```

噪声：

```math
Z_i\sim N(0,N)
```

容量：

```math
C=\max_{p(x):E[X^2]\le P} I(X;Y)
```

推导：

```math
I(X;Y)=h(Y)-h(Y|X)=h(Y)-h(Z)
```

由于给定方差时高斯分布微分熵最大：

```math
h(Y)\le \frac{1}{2}\log(2\pi e(P+N))
```

于是：

```math
C=\frac{1}{2}\log\left(1+\frac{P}{N}\right)
```

等号在输入 `X` 为高斯分布时成立。

例：若 `P/N=15`，则

```math
C=\frac{1}{2}\log_2(16)=2 bit/use
```

### 7.2 高斯信道编码定理

噪声方差为 `N`、输入功率约束为 `P` 的 AWGN 信道上：

- 任何 `R<C` 的速率可达。
- 任何 `R>C` 的速率不可达。

注意课件讨论中的两个理想条件：

1. 香农定理要求码长趋于无穷。
2. AWGN 容量等号要求高斯输入。

因此实际系统的错误概率不可能真正为 0，只能通过较长码长、较好编码和调制逼近理论极限。

### 7.3 高斯平行信道与注水法则

平行高斯信道：

```math
Y_i=X_i+Z_i,\qquad Z_i\sim N(0,N_i)
```

总功率约束：

```math
\sum_{i=1}^k P_i\le P
```

容量优化：

```math
\max \sum_{i=1}^k \frac{1}{2}\log\left(1+\frac{P_i}{N_i}\right)
```

注水法则：

```math
P_i=(\gamma-N_i)^+
```

其中 `gamma` 由总功率约束确定。

含义：给噪声小的子信道分配更多功率；噪声高于水位的子信道不分配功率。

应用背景：OFDM、CDMA、MIMO。

### 7.4 带限模拟高斯信道容量

带宽限制在 `[0,W] Hz`，信道：

```math
y(t)=x(t)+z(t)
```

由 Nyquist 采样，`T` 秒内等价于约 `2WT` 次平行离散传输。

若白噪声双边功率谱密度为 `N_0/2`，则模拟高斯信道容量：

```math
C=W\log\left(1+\frac{P}{N_0W}\right)
```

单位：bit/s。

### 7.5 传输 1 bit 的最小能量与功率带宽互换

频谱效率：

```math
\eta=\frac{R}{W}
```

每 bit 能量：

```math
\epsilon_b=\frac{P}{R}
```

由容量公式可得：

```math
\epsilon_b^*(\eta)=\frac{N_0}{\eta}(2^\eta-1)
```

当 `eta->0`：

```math
\epsilon_b^*(0)=N_0\ln 2
```

功率与带宽关系：

```math
C=W\log\left(1+\frac{P}{N_0W}\right)
```

固定容量 `C` 时：

```math
P(W)=\left(2^{C/W}-1\right)N_0W
```

结论：

- 带宽越大，达到同样速率所需功率越小。
- 最小功率极限：

```math
P_{\min}=N_0C\ln 2
```

- 在 AWGN 信道上，信息传输得越慢越省能量。
- 但实际系统还受带宽资源、硬件、同步、调制方式和码长限制。

课件启示：

- 宽带技术如 CDMA、OFDM 有功率效率优势。
- 高阶调制如 16QAM 的功率效率不一定优于 QPSK。
- 低能耗传感器网络中，数据量小、能量有限时，低阶调制和低速率传输更有利。

## 8. 复习时最容易混淆的点

### 8.1 熵、互信息、KL 散度的区别

| 量 | 公式 | 作用 |
|---|---|---|
| 熵 | `H(X)` | 单个随机变量的不确定性 |
| 条件熵 | `H(X|Y)` | 已知 `Y` 后 `X` 的剩余不确定性 |
| 互信息 | `I(X;Y)=H(X)-H(X|Y)` | `Y` 平均减少了多少关于 `X` 的不确定性 |
| KL 散度 | `D(p||q)` | 用 `q` 代替 `p` 的分布差异/额外代价 |

### 8.2 条件熵与条件自信息

- 对具体事件，`I(x|y)` 可能大于也可能小于 `I(x)`。
- 对平均量，`H(X|Y)<=H(X)`。

### 8.3 事件互信息与平均互信息

- `I(x;y)` 可以为负。
- `I(X;Y)` 一定非负。

原因：具体观测可能“误导”某个事件，但平均意义下观测不会减少信息。

### 8.4 离散熵与微分熵

- 离散熵 `H(X)>=0`。
- 微分熵 `h(X)` 可正、可负、可为 0。
- 微分熵依赖尺度，互信息更稳定。

### 8.5 信源编码定理与信道编码定理

| 定理 | 关注对象 | 极限 |
|---|---|---|
| 信源编码定理 | 压缩 | 码率不能低于熵 `H` |
| 信道编码定理 | 传输 | 码率不能高于容量 `C` |
| 分离定理 | 压缩后传输 | 只要 `H<C` 就可可靠传输 |

### 8.6 “无差错”的含义

- 等长 Shannon 信源编码和信道编码中的“可靠”通常是渐进意义：块长趋于无穷时错误概率趋于 0。
- 绝对无差错编码要求每个有限长度都零错误，条件更强。

## 9. 快速例题

### 例 1：自信息

事件发生概率 `p=1/16`，则：

```math
I=-\log_2(1/16)=4 bit
```

解释：要从 16 个等可能事件中指出一个，需要 4 个二元问题。

### 例 2：二元熵

若 `P(X=1)=0.9`：

```math
H(X)=-0.9\log_2 0.9-0.1\log_2 0.1\approx 0.469 bit
```

不是 1 bit，因为变量大多数时候可预测。

### 例 3：前缀码平均码长

信源概率 `{0.5,0.25,0.25}`，码 `{1,00,01}`：

```math
\bar n=0.5\times1+0.25\times2+0.25\times2=1.5 bit
```

熵：

```math
H=1.5 bit
```

因此这是最优码。

### 例 4：BSC 容量

BSC 交叉概率 `p=0.1`：

```math
C=1-H_2(0.1)\approx 1-0.469=0.531 bit/use
```

若传输速率 `R<0.531`，理论上存在可靠编码；若 `R>0.531`，不可能让错误概率趋于 0。

### 例 5：AWGN 容量

若 `P/N=3`：

```math
C=\frac{1}{2}\log_2(1+3)=1 bit/use
```

若是带限模拟信道，带宽 `W=1 MHz`，`P/(N_0W)=3`：

```math
C=W\log_2(1+3)=2 Mbps
```

## 10. 建议复习顺序

1. 先背熟四个基本量：`I(x)`、`H(X)`、`I(X;Y)`、`D(p||q)`。
2. 再掌握四条链式法则：熵链式、互信息表达式、条件互信息链式、数据处理。
3. 信源编码重点看：AEP、典型集、Kraft、不等长编码定理、Huffman。
4. 信道容量重点看：`C=max I(X;Y)`、BSC/BEC/对称信道、KKT 条件。
5. 信道编码重点看：随机编码、联合典型译码、Fano 逆定理。
6. 高斯信道重点看：`1/2 log(1+P/N)`、注水法则、`W log(1+P/(N0W))`。

## 11. 概念之间的逻辑关系梳理

学习信息理论时，最容易卡住的地方不是某个公式本身，而是不知道这个公式在整套理论里负责什么。可以把本课程的概念关系理解成一条主线：

```text
概率模型
  -> 信息度量
  -> 信源极限：最少需要多少 bit 表示？
  -> 信道极限：最多能可靠传多少 bit？
  -> 编码定理：怎样证明这些极限可达或不可突破？
  -> 高斯信道：把离散信道思想推广到连续噪声通信系统
```

### 11.1 从概率模型到信息度量

一切概念都从概率分布开始。没有概率，就谈不上“不确定性”；没有不确定性，就没有信息量。

```text
随机变量 X
  -> 概率分布 p(x)
  -> 自信息 I(x)=-log p(x)
  -> 熵 H(X)=E[I(X)]
```

这里的逻辑是：单个事件越罕见，自信息越大；把所有事件按概率加权平均，就得到随机变量的平均不确定性，即熵。熵不是“消息内容的重要程度”，而是“在不知道结果前，平均还需要多少 bit 才能说明结果”。

如果引入另一个随机变量 `Y`，就会出现“知道 `Y` 后，`X` 还剩多少不确定性”的问题：

```text
联合分布 p(x,y)
  -> 条件分布 p(x|y)
  -> 条件熵 H(X|Y)
  -> 互信息 I(X;Y)=H(X)-H(X|Y)
```

互信息是连接“信息度量”和“通信系统”的核心桥梁。它既可以理解为 `Y` 平均减少了多少关于 `X` 的不确定性，也可以理解为输入 `X` 经过信道后，输出 `Y` 保留下来的有效信息。

### 11.2 熵、条件熵、互信息、KL 散度的关系

这几个量可以按“一个变量、两个变量、两个分布”来区分：

| 概念 | 关心什么 | 典型问题 |
|---|---|---|
| 自信息 `I(x)` | 一个具体事件有多意外 | 看到这个结果获得多少信息？ |
| 熵 `H(X)` | 一个随机变量平均有多不确定 | 这个信源平均每个符号含多少 bit？ |
| 条件熵 `H(X|Y)` | 已知 `Y` 后 `X` 还剩多少不确定 | 观测之后还不知道多少？ |
| 互信息 `I(X;Y)` | `X` 和 `Y` 共享多少信息 | 输出告诉了我们多少输入信息？ |
| KL 散度 `D(p||q)` | 两个分布差多少 | 用错误模型 `q` 代替真实模型 `p` 额外损失多少？ |

它们之间最重要的关系是：

```math
I(X;Y)=H(X)-H(X|Y)=D(p(x,y)||p(x)p(y))
```

所以互信息也可以看成一种 KL 散度：它衡量联合分布 `p(x,y)` 与独立分布 `p(x)p(y)` 的差距。若二者相等，说明 `X` 和 `Y` 独立，互信息为 0；差距越大，说明相关性越强。

### 11.3 从熵到信源编码：为什么压缩极限是 H

信源编码回答的是：

```text
信源产生符号
  -> 符号有概率分布
  -> 每个符号平均信息量为 H
  -> 无损表示这些信息，平均码率不能低于 H
```

因此，熵是“压缩下限”。如果每个符号平均只有 `H(X)` bit 的真实不确定性，那么理论上就不应该长期用远多于 `H(X)` 的 bit 去表示；但也不能长期少于 `H(X)`，否则会丢失区分典型序列所需的信息。

AEP 和典型集解释了这个极限为什么成立：

```text
长序列总数 K^n 很大
  -> 但高概率序列主要集中在典型集
  -> 典型集大小约为 2^{nH}
  -> 只需约 nH bit 就能编号这些典型序列
```

Huffman、Shannon、Fano、Shannon-Fano-Elias 等编码方法，是在不同约束下逼近这个极限的具体算法。Kraft 不等式则是判断码长能否构成前缀码的结构条件。

### 11.4 从互信息到信道容量：为什么传输极限是 C

信道编码回答的是另一个问题：

```text
输入 X 经过信道 p(y|x)
  -> 输出 Y 是带噪声的观测
  -> I(X;Y) 表示一次信道使用保留下来的有效信息
  -> 对输入分布 p(x) 优化，得到容量 C=max I(X;Y)
```

所以容量不是信道“输出了多少 bit”，而是“输入和输出之间最多能建立多少可靠对应关系”。噪声越大，`H(X|Y)` 越大，互信息越小，容量越低。

典型信道可以用同一个模板理解：

| 信道 | 噪声表现 | 容量直觉 |
|---|---|---|
| 无噪信道 | 输出能确定输入 | `C=log M` |
| 无用信道 | 输出与输入独立 | `C=0` |
| BSC | 符号可能翻转且不知道哪里错 | `C=1-H_2(p)` |
| BEC | 符号可能擦除但知道哪里丢 | `C=1-epsilon` |
| 对称信道 | 每个输入受噪声方式相同 | 均匀输入通常最优 |

信道容量优化中的 KKT 条件，本质是在说：最优输入分布下，所有实际使用的输入符号对互信息的边际贡献应当相等；贡献低的符号就不该使用。

### 11.5 信源编码和信道编码如何接起来

压缩和传输是两个方向相反的极限：

```text
信源编码：把冗余去掉
  目标：码率 R_s 尽量接近 H
  约束：R_s >= H

信道编码：给消息加冗余以抗噪
  目标：传输速率 R_c 不超过 C
  约束：R_c <= C
```

分离定理把这两部分接起来：

```text
信源熵率 H
  < 信道容量 C
  -> 可以先压缩，再加信道编码，可靠传输
```

这里有一个容易混淆的点：信源编码去冗余，信道编码加冗余，看起来方向相反，但目的不同。信源编码去掉的是信源自身的统计冗余；信道编码加入的是为了抵抗信道噪声而设计的校验冗余。

### 11.6 Fano 不等式和数据处理定理的位置

Fano 不等式和数据处理定理常出现在逆定理里，它们不是孤立技巧，而是用来证明“不可能性”的工具。

```text
数据处理定理：
W -> X^n -> Y^n -> W_hat
处理不会凭空增加关于 W 的信息
所以 I(W;W_hat) <= I(X^n;Y^n) <= nC
```

```text
Fano 不等式：
若译码错误概率很小
则 H(W|W_hat) 也必须很小
所以 I(W;W_hat) 必须接近 H(W)=nR
```

把两者合在一起：

```text
可靠译码要求 I(W;W_hat) 约等于 nR
信道最多只能提供 nC 的互信息
因此必须 R <= C
```

这就是信道编码逆定理的核心逻辑。

### 11.7 离散信道到高斯信道的对应关系

高斯信道看起来公式不同，但逻辑仍然是“最大互信息”：

```text
DMC：C=max_{p(x)} I(X;Y)
AWGN：C=max_{p(x):E[X^2]<=P} I(X;Y)
```

AWGN 中：

```math
Y=X+Z,\qquad I(X;Y)=h(Y)-h(Z)
```

噪声 `Z` 固定时，要最大化互信息，就要在功率约束下让输出 `Y` 的微分熵尽量大。由于固定方差时高斯分布微分熵最大，所以最优输入也是高斯分布，得到：

```math
C=\frac{1}{2}\log\left(1+\frac{P}{N}\right)
```

平行高斯信道的注水法则也是同一思想：总功率有限时，把功率优先分配给噪声小、能更有效产生互信息的子信道；噪声太大的子信道不使用。

### 11.8 一条总复习路线

可以按下面这条路线把全课串起来：

```text
1. 概率分布 p(x)
   -> 自信息 I(x)
   -> 熵 H(X)

2. 联合分布 p(x,y)
   -> 条件熵 H(X|Y)
   -> 互信息 I(X;Y)
   -> 数据处理定理

3. 信源 X_1,X_2,...
   -> 熵率 H_infty
   -> AEP / 典型集
   -> 无损压缩极限
   -> Huffman 等具体编码

4. 信道 p(y|x)
   -> 一次传输的互信息 I(X;Y)
   -> 最大化得到容量 C
   -> 随机编码证明可达
   -> Fano 证明不可超过

5. 连续噪声信道
   -> 微分熵 h(X)
   -> 高斯最大熵
   -> AWGN 容量
   -> 注水法则和功率-带宽互换
```

一句话总结：`H` 描述信源“最少要说多少”，`C` 描述信道“最多能听懂多少”，`I(X;Y)` 是连接二者的桥梁，AEP/典型集说明极限为什么可达，Fano/数据处理说明极限为什么不能突破。
